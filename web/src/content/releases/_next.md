What the next release has to say before anybody updates to it. A change that alters what a
project or a setting does adds its line here. Each nightly's GitHub release carries the
section below, and when the release note is written the lines move into it.

## Before you update

- Sprite flare's light now runs to white where it is brighter than full, because **Burn** starts at 100. Set **Burn** to 0 to keep a flare as it was.
- Depth of field pro no longer lets what is under the layer show through where its highlights are.
- An adjustment layer now uses its blend mode, where it was always drawn as Normal. A project with a mode other than Normal on an adjustment layer will look different.
