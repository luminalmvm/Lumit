Lumit now has three interface styles and twelve new colour themes. Addons are in, with the first local models for depth,
background removal, frame synthesis, and the Roto brush. The node graph has several improvements, the Viewer draws motion paths, and fixes from the backlog.

## What is new

### Styles and themes

- Two new interface styles, Desk and Lantern, beside the old one, which is now called Studio. Switch between them under Settings ▸ Appearance ▸ Shape.
- Twelve new colour themes, each with a light and a dark variant.
- The toolbar can sit on the left, and the Viewer has a Deck arrangement.
- Range sliders on effect rows can be turned off.
- The Round style is gone, and a workspace saved with it opens as Lantern.

### Addons

Addons are still experimental and may be updated going forward. So please give feedback. Currently they provide some ML models to assist in certain areas of the program. We will never add genAI to addons. Going forward we also want to open this up to be able to install addons from other users. 

- Settings has an Addons page. It lists what is installed, and Check for addons shows what else is available.
- The first packs are **Depth** generation, **Remove background**, RIFE frame
  synthesis as an Engine option under Flow, and SAM 2 seeding for the Roto brush.

### Node graphs

- The Timeline shows the node graph under the ruler when a node graph comp is open, and
  the effect controls show the picked box's properties (requested by @Airyzz in #153).
- Effects can be dragged in from Effects & presets, and right click, Tab, or Shift+A
  open node search at the pointer. Each can be turned off under Settings ▸ Timeline.
- Boxes copy and paste, and undo removes a paste in one step.
- **Split channels** and **Combine channels** boxes. Combine takes luminance from each
  input by default, or a channel picked per input.
- An **Expression driver** box, with Value, Colour, Point x, and Point y outputs.

### The Viewer

- A selected layer's motion path is drawn as a wireframe.
- A layer with keyed position now has a box in the Viewer, so it can be picked on the picture.

### Audio

- Audio effects on a Precomp layer now work and treat precomp audio as a single audio source.
- Detect beats shows how far it has progressed.

### Smaller things

- The scroll wheel modifiers can be changed under Settings ▸ Shortcuts ▸ Scroll wheel,
  for zooming the Timeline, scrolling it sideways, zooming graph values, and the dropper
  sample size (requested by @politohh).
- An image sequence's frame rate can be set from its menu in the project panel.
- Levels has channel buttons, so its handles work on one channel at a time.
- The command palette remembers what you last ran after Lumit closes, and every row shows its shortcut.
- Timeline twirls and effect control folds are saved with the project.
- Footage Lumit can't decode shows an unreadable badge rather than importing silently.
- An After Effects project whose layers can't be read now imports its footage anyway and explains the issue. Casts Shadows and keyframed dropdowns in colour effects are reported too.
- Scanlines and the lens flare scale with the comp size, so a precomp at a different size looks the same.
- OFX bundles that keep their own DLLs beside the plugin now load (reported by @politohh).
- Pixel sort has a **Random offset scale** control, and a span can be up to 4096 pixels long rather than 1024, so it can cover the whole width of a larger picture (with fixes from @Airyzz in #175).
- Arabic and Brazilian Portuguese are on the translation page and in the language list.

## Performance

- The effect controls redraw far less when you pick or delete an effect.
- Clicking a row in the project panel rebuilds far fewer widgets.
- Corner detection is faster.
- Layers hidden under a rotated or scaled layer that covers the frame are no longer drawn for increased render speeds. 

## Fixed

- On laptops with two graphics cards the Viewer was blank while the sound played (reported by @liquidsvfx).
- Dragging a keyed mask's points in the Viewer snapped back on release, and Delete key on a Path key did nothing (reported by @edup).
- Pressing Delete in the effect controls, or on an effect row in the Timeline, deleted the layer.
- Effects and presets were added to every selected layer instead of one.
- Relinked footage on a different drive to the project went missing again on reopen.
- After a relink the Viewer kept showing colour bars and the missing files count, and the clip had no speaker switch.
- A relinked image sequence kept its old frame range.
- Double clicking the relink badge opened New composition.
- The glow had a hard square edge at high intensity.
- Switching from graph view back to layer view scrolled the lane area to the top.
- Plugin on/off parameters never reached the plugin.
- Mirror, Lens distort, Drop shadow, Transform, Shake motion blur, Directional blur, and Radial blur could leave a stray pixel at the edge of the frame.
- Clicking a switch on a locked layer threw an error.
- A crash before a project was opened wasn't written to the crash log.
- The Settings scrollbar thumb jumped.
- Lumit's icon was missing on Linux (with fixes from @Airyzz in #176).
- Boxes in the node graph were drawn outside of its panel (with fixes from @Airyzz in #177).
- Edit shader and Load from file did nothing on a Custom shader box in a node graph, and the node panel's buttons were greyed out.
- Rows declared by a Custom shader, such as Gain or Tint, had no socket in the node graph, so nothing could be wired into them.

## Before you update

- The glow is drawn differently, so projects with a glow will look a little different. This is most noticeable with Falloff values above 0.
- Beat tap has moved from 8 to the / key, since the number keys now create numbered markers.

## Known gaps

- Motion path tangent handles are drawn but can't be dragged yet, and the path redraws on release.
- Arabic reads left to right for now.

I will be gone for the next two weeks, once I return all work on Lumit will no longer use AI assistance. Thanks very much for all the reports and requests that went into this release. I hope this fixes some of the issues people had and you can enjoy using Lumit!
