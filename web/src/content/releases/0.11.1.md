A small follow-up to 0.11.0, so the values on node boxes can be set again.

## Fixed

- The values on an open box in the node graph could only be read. They can be dragged and typed into again, as well as in the Node panel.
- The Value, Speed and Acceleration switch, Speed profile and Gravity in the Graph editor, and the two retime switches were round whatever style was picked. They now take the style's own corners.
