A small follow-up to 0.3.0. Mainly just some small fixes to crashes and issues 
launching the program. Also fixes updating from inside Lumit not working, so you will
have to install this version manually again (sorry), but all future versions with any
luck can be updated from within the application.

## Fixed

- Updating from inside Lumit downloaded the update, offered a restart, and then did
  nothing, this was found on windows, macOS and Linux are still.
- Lumit crashed when a value was dragged while the timeline was playing, and when a 
  clip carrying retime was scaled.
- A panel whose contents could not be drawn showed a blank grey rectangle. It now
  displays the fault and writes it to the diagnostics file.
- Opening a project while one was already open left panels reading the closed
  project.
- A start-up that failed before the window appeared left Lumit running while displaying
  nothing. It now opens a window explaining the error.
- The start-up scan opened console windows when finding plugins.
- OFX plugins that set their own controls while loading refused to apply.
- An OFX suite installed in a folder of its own was not found.
- Linux and macOS ran Flutter's Impeller renderer rather than Skia.
- On Linux the window asked to be maximised before it existed.
- In the Graph editor's speed view, a dragged keyframe ran ahead of the pointer and
  jumped back to the pointer when it was released.

## What is new

- **Settings ▸ Performance ▸ Full resolution while dragging** renders a value drag at
  the Viewer's own resolution rather than the reduced one. Off by default.
