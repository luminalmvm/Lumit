# SICELIOT

Cavalry-style, non-destructive effects for Lumit, from SICELIOT.
The engine side is the fourteen commits before this
folder in the same pull request; this folder holds the rest.

| Folder | What it is |
| --- | --- |
| `.` | The `siceliot` LFX extension: 19 picture effects under **Siceliot FX**. Install the folder, or package it, as any extension. |
| `docs/SICELIOT.md` | The one-page overview: every effect, every engine change, how to install. |
| `docs/en/`, `docs/it/` | The full documentation in English and Italian: effects, engine changes, examples, building. |
| `docs/research/` | Notes comparing Cavalry and Lumit. |
| `docs/images/` | The renders the documentation shows. |
| `examples/` | `flood.lum` and `sketch.lum`, the projects described in `docs/en/examples.md`. |

The documentation is copied as written in the SICELIOT repository: paths such as
`D:\Siceliot\Lumit` are the author's checkout of this repository, and links to `patches/` point at
the engine commits kept there as patch files, which this pull request carries as commits instead.

The glass effect, Reaizzi Glass, is in [`../reaizzi-glass`](../reaizzi-glass/README.md).
