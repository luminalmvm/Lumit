Every available effect can be found in this panel grouped by category.
Presets saved to the application's preset folder also appear at the top.

| Group | What it holds |
| --- | --- |
| **Built-in** | Effects that ship with Lumit. |
| **Presets** | Saved presets which can hold keyframes and multiple effects values. |

:::note[Not yet built]
The star icon is for favourited effects, which is not completed yet.
OFX for third-party effects, and LFX, Lumit's own plugin format, are both planned.
:::

<Shot file="effects-presets.png" caption="The Effects & presets panel." eager/>

## Apply one

Drag an effect onto a layer. You can also select layers and double-click the effect.
The **Effect** menu does the same job.
