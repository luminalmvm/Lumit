Scopes read the frame the Viewer previews.

| Scope | Shows |
| --- | --- |
| **Waveform** | Brightness against horizontal position. |
| **Vectorscope** | Hue and saturation on a colour wheel. |
| **Histogram** | How many pixels sit at each level. |
