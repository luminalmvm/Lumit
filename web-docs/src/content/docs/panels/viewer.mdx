The Viewer displays the composition preview at the playhead. Its bar carries controls that
can alter how the picture is displayed in the preview. None of these alter exports.

<Shot file="viewer.png" caption="The Viewer, with a layer selected and its transform gizmo showing." eager/>

## The Viewer bar

<Shot file="viewer-bar.png" caption="The Viewer bar." eager/>

| Control | Does |
| --- | --- |
| **Magnification** | Zoom level. Zooming is anchored on the pointer. |
| **Preview resolution** | Full, half, third, quarter, or auto. |
| **Region of interest** | Tool to isolate a specific area of the frame to increase preview speed. |
| **Transparency grid** | Draws a chequerboard behind alpha to help visualise transparency. |
| **Grid and guides** | Overlays a line grid or safe zones in your composition. |
| **Hide layer controls** | If enabled, will hide the wireframes that appear on layers. |
| **Composition background** | Changes the displayed background color when the background is visible. |
| **Channel view** | Show RGB, individual channels, or alpha. |
| **Exposure** | Changes the exposure within the preview. |
| **Take snapshot** | Saves a copy of the current preview image and enables the Preview snapshot option. |
| **Preview snapshot** | While holding, displays the recorded snapshot, to help compare changes. |
| **Current time** | The playhead's time. |
| **Playback type** | Select between **Every frame** or **Adaptive res** options. |
| **Playback controls** | Go to first/previous/next/last frame, or start/pause playback. |
| **Display transform** | Displays the color conversion. |
| **Degradation indicator** | Appears when the engine has lowered quality to maintain realtime plack in Adaptive res. |

Viewer bar options do not affect exports in any way, they only alter the preview image. See [Preview and playback](/use/preview/).

## In the preview

Select a layer and the Viewer displays its wireframe with a transform gizmo by default. The
handles move, scale and rotate the layer. See [Transforming layers](/use/transform/).

:::note[Not yet built]
Motion paths, where a keyed position draws its path over the picture, are not built yet.
:::
