The graph editor shows a property as a curve. It edits the same data the timeline
does - it is a view, not a copy.

| Control | Does |
| --- | --- |
| **Value graph** | Value against time. |
| **Speed graph** | Rate of change against time. |
| **Lens switch** | Swap between the two. |
| **Auto view** | Frame the selected curves. |

On a retimed layer the Retime channel labels its value lens **Time** and its derivative
lens **Speed** — how fast the source plays, in per cent.
