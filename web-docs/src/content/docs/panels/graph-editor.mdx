The graph editor draws a property's value as a line. It is the Timeline's **Graph** mode,
over the same ruler, zoom and scroll as the lanes. `Shift+F3` switches to it and back.

<Shot file="graph-editor.png" caption="The graph editor, showing the value graph." eager/>

A property's curve is drawn while its row is selected in the outline. A property with two
axes draws a curve for each. With no row selected, the animated curves of the selected
layers are drawn.

## Controls

In the graph's top right corner, **Value**, **Speed** and **Acceleration** pick the graph:
value against time, rate of change against time, or how fast the speed changes. On a
narrow graph the three fold into one word.

Under the outline:

| Control | Does |
| --- | --- |
| **Linear**, **Easy ease**, **Hold** | Sets the interpolation of the selected keyframes. See [Altering keyframe types](#altering-keyframe-types). |
| **Easing…** | Opens the [Easing panel](/panels/easing/), or a popup with **Settings ▸ Timeline ▸ Panels ▸ Shape eases in a popup** on. Value graph only. |
| **Auto**, **Clamp**, **Free** | Puts the selected keyframes' handles in that tangent mode. See [Tangent modes](#tangent-modes). |
| **Break handles** | Each handle of a keyframe moves without the other. Off each time Lumit starts. |

Under the graph:

| Control | Does |
| --- | --- |
| **Zoom** | Zooms time, as in Layers mode. |
| **Magnet** | Turns snapping on and off. |
| **Scope** | Steps through **Selected curves**, **Layer curves** and **Composition curves**. Curves shown but not selected are dashed; a click selects one, and `Shift`-click or `Ctrl`-click adds it. |
| **Auto fit** | Automatically adjusts the vertical zoom to fit the curve on screen. Zooming the values with the wheel, or moving them with a middle-button drag, turns it off. |
| **Fit selection** | Zooms time and value to the selected keyframes, or to every curve with none selected. `F` does the same, and `Shift+F` frames every curve. |

| Right-click on | Holds |
| --- | --- |
| A keyframe | **Linear**, **Easy ease**, **Easy ease in**, **Easy ease out**, **Hold**, **Tangents**, **Ease…**, **Keyframe speed…**, **Join handles**, **Reverse** with several selected, **Copy**, **Paste**, **Copy ease**, **Paste ease**, **Delete keyframe**. |
| A curve | **Add keyframe here**, **Linear**, **Easy ease** and **Hold** for the stretch between two keyframes, **Solo**, **Hide**, **Select keyframes**, **Copy**, **Paste**, **Reset**. |
| A handle | **Flatten**, **Join handles**, **Break handles**, **Linear**, **Keyframe speed…**. |
| The empty plot | **Add keyframe at playhead**, **Paste**, **Select all keyframes**, **Frame selected** (`F`), **Frame all** (`Shift+F`), **Auto fit**, the three graphs, the three scopes, **Show all curves** with any hidden, **Snap**. |

With more than one curve on the graph, a list in its corner names them. A click on a row hides
or shows the curve, `Alt`-click solos it, and a right-click adds **Rename layer** to the curve's
menu. The arrow at the top of the list folds it down to a stroke of each curve's colour.

With **Edit ▸ Settings ▸ Timeline ▸ Editing ▸ Retime opens to Speed** on, a Retime curve
opens on the speed graph. See [Retiming and speed](/use/retime/).

## Altering keyframe types

When working in the graph editor you can use the **Linear**, **Easy ease**, or **Hold** buttons to
alter the change between frames. Linear has a constant rate of change between keyframes, and hold
will hold the last keyframe until it reaches a new one.

Easy ease gives a keyframe two bezier handles, which by default move together, but holding `Alt` as a
handle drag begins allows them to act independently. These can be used to influence and change the rate of change between
keyframes.

Altering keyframes in both the value and speed graph will reflect in the other.

| Shortcut | Does |
| --- | --- |
| `F9` | Easy ease on both sides of the selected keyframes. |
| `Shift+F9` | Easy ease on the side coming in. |
| `Ctrl+Shift+F9` | Easy ease on the side going out. |

The three work in Layers mode too.

## Tangent modes

| Mode | The handle |
| --- | --- |
| **Free** | Stays where it is dragged. |
| **Auto** | Points along the line from the keyframe before to the keyframe after. On the first and last keyframe it lies flat. |
| **Clamp** | As Auto, limited so the curve cannot pass beyond either neighbour's value. On a peak or a trough it lies flat. |

A handle keeps its reach in every mode. Dragging an Auto or Clamp handle makes it Free. A
handle sent to Auto or Clamp and back to Free returns to the shape it had.

## Keyframes

| Action | How |
| --- | --- |
| Select | Click a keyframe. `Shift`+click adds it to the selection, and `Ctrl`+click adds or drops it. |
| Select several | Drag a box over empty pane. `Shift` or `Ctrl` as the drag begins adds to the selection. |
| Deselect | Click empty pane. |
| Move | Drag a selected keyframe. Every selected keyframe moves by the same amount. `Shift` keeps the drag to time or to value, whichever the pointer has moved further along. |
| Add | Double-click the curve, or `Ctrl`+click it. The new keyframe holds the value the curve reads there. |
| Remove | `Alt`+click a keyframe, select it and press `Delete`, or right-click it: **Delete keyframe**. |
| Type exact numbers | Double-click a keyframe for its **Frame**, **Value**, and **In** and **Out** influence. |
| Move the middle of an ease | Hold `Shift` and drag the curve between two keyframes sideways. Each keeps its speed. |
| Abandon a drag | `Esc` while the button is down. |

`Alt`+click does not remove a curve's last keyframe. Deleting it with `Delete` leaves the
property at the value that keyframe held.

With the **Pen** tool armed, a click on the curve adds a keyframe. A click on a keyframe
selects it, as with any tool.

One selected keyframe carries a readout of its frame, its value, and its in and out
influence. Click the readout to type its speed and influence on each side. The foot of the
outline shows the same frame and value, with its **In** and **Out** influence to type, and
the [Easing panel](/panels/easing/#one-keyframes-numbers) shows its speed and influence.

A dragged keyframe snaps to markers, the playhead, work-area edges, layer ends and edit
points while the magnet is on. `Ctrl` suspends it.

`Ctrl+C` and `Ctrl+V` copy and paste the selected keyframes. See
[Keyframes](/use/keyframes/#copy-and-paste).

## Handles

A selected keyframe shows its handles, and so do the sides of its neighbours that face it.

- Drag a handle to change the curve's shape.
- Hold `Shift` while dragging to lay the handle flat.
- Hold `Alt` as the drag begins to move that handle without its partner, or to join two that
  were apart. **Break handles** does the first with no key held.
- **Join handles**, on a keyframe's right-click menu, joins handles that were apart.
- With several keyframes selected, dragging a handle on one moves the same handle on each
  by the same amount.

**Edit ▸ Settings ▸ Shortcuts ▸ Dragging** changes `Alt` to `Ctrl`.

In the speed graph each keyframe is two points, one for the speed coming in and one for
the speed going out. Drag a point up or down to set that side's speed, and sideways to move
the keyframe in time. Each point has one handle, which sets that side's influence.

In the acceleration graph each keyframe has an in dot and an out dot. See
[the graph editor](/use/graph-editor/#the-acceleration-graph).

## The selection box

Two or more selected keyframes are drawn inside a box, with a badge reading how many it
holds and how many frames it spans.

- Drag the left or right edge to scale the keyframes in time about the opposite edge.
- Drag the top or bottom edge to scale their values about the opposite edge.
- Hold `Shift` to land the scale on whole frames and whole numbers.

While an edge is dragged, a readout gives the frames the box spans and the values at its
bottom and top.

## Moving about

- **Ctrl+wheel** zooms time, and **Shift+wheel** scrolls sideways, as in the lanes.
- **Alt+wheel** zooms the values about the pointer.
- With **Auto fit** off, **the wheel** scrolls the values.
- A drag with the **Hand** tool pans the curves.
- **A middle-button drag** pans time and values. With `Ctrl` held as it begins it zooms about
  where the drag began: right and left zoom time in and out, up and down the values.

**Edit ▸ Settings ▸ Shortcuts ▸ Scroll wheel** changes which key does which.

## What else is drawn

- A grid rules the plot by value and by frame, with fainter lines between them where there
  is room. The values are numbered down the right edge.
- A mask's **Path** row has no value to plot. It draws its rate of change in the value
  graph too.
- An [expression](/use/expressions/) draws as a curve with no keyframes.
- A marker's [region](/use/markers/#regions) is shaded down the pane, and each marker draws
  its line.
