The Project panel holds everything imported, every composition, and everything else made
outside a timeline.

<Shot file="project-panel.png" caption="The Project panel, holding a folder of compositions, sound, footage with a proxy attached, and a still." eager/>

| Item | What it is |
| --- | --- |
| **Footage item** | A reference to a media file on disk. |
| **Audio item** | A reference to a sound file on disk. |
| **Composition** | A timeline. It can be used as footage inside another composition. |
| **[Node graph](/use/node-graphs/)** | A composition made of boxes and wires. Its row wears the nodes glyph and the type word *Node graph*. |
| **Folder** | A grouping inside the panel. It creates no folder on your computer. |
| **Solid** | A solid colour. |

Top to bottom the panel is a search well with the colour filter inside it, a row of column
headings, the tree, a preview card while one item is selected, and a bottom bar.

Click a column heading to sort the tree by that column, and again to reverse the order. A
folder keeps its own items. The sort lasts until the panel is closed. Right-click the empty
space in the tree for **Sort by**, **Expand all**, **Collapse all**, and everything new.

A file or solid no composition uses has a muted name.

## Columns

| Column | What it reads |
| --- | --- |
| **Items** | How many things a folder holds. |
| **Size** | Pixel dimensions, or a sound file's sample rate. |
| **FPS** | Frame rate. Blank for sound. |
| **Duration** | Length as `HH:MM:SS:FF` at the item's own rate; `HH:MM:SS:mmm` for sound. Blank for folders and stills. |
| **Date** | When a footage item's file was last changed. |
| **Path** | The folder a footage item's file is in. |

Columns leave as the panel narrows, Date first, then Path, then Duration. Dragging the seam
between two headings widens the column on its left. Right-click a heading to hide a column,
or **Reset columns**.

**Thumbnails on footage rows**, in **Settings ▸ Appearance ▸ Panels**, draws each footage
row's first frame in place of its glyph, at the row's height. Off by default.

## The preview card

Select one item and the card under the tree shows what Lumit knows about it: a thumbnail, the
name, the facts (resolution, frame rate, duration, codec) and how many times it is used.
Sound reads its rate and channels; a folder reads how many items it holds. With nothing
selected, or several, there is no card. Hover the count on the bottom bar for what the project
holds.

Move the pointer across the thumbnail to scrub the clip. Leaving it puts the first frame
back. A still and a sound file have nothing to scrub.

A sound file carries a play button where the thumbnail would be. It plays the file from
the start, with no composition behind it. Pressing it again stops it, and so does
selecting something else or playing a composition.

## Bringing things in

- **Drag files onto the panel** from your file manager. This is the same command as
  **File ▸ Import footage**, so a batch is one undo step and image sequences are spotted
  for you.
- **Drop a folder** and the files Lumit can take come in from it and every folder inside it,
  filed in project folders of the same names.
- **Double-click empty space** in the tree to open the import dialogue.

Files dropped anywhere else on the Lumit window are imported the same way.

A `.lum` project, or an After Effects `.aep` or `.zip`, is *not* opened by dropping it —
import those from the menu.

## Clicking and opening

A click selects. A double-click **opens** the row.

| Item | What opening does |
| --- | --- |
| **Composition** | Fronts it in the Viewer and Timeline. |
| **Node graph** | Fronts it in the Node graph panel. |
| **Footage** | Raises **New composition** with the resolution, frame rate and length already matched to it. |
| **Folder** | Shows or hides its children. |

Footage, composition and solid rows drag onto the Timeline, where a composition lands as a
Precomp layer and a solid as a Solid layer. **Add to composition** on the row's menu does the
same, and **Reveal in composition**, or a click on the card's uses line, opens the
composition that uses the item with those layers selected. An item used in several lists
them to pick from. Dropped onto **New composition** on the bottom bar instead, they raise the same New
composition dialogue with the media's size, rate and length filled in, and every dropped item
lands in the finished composition as a layer.

Renaming is `Enter`, or **Rename** on the row's own menu.

`Ctrl+D`, or `Ctrl+C` then `Ctrl+V`, duplicates the selected items. `Delete` removes them,
along with everything inside a folder and any layers, effects or node graph boxes that use
them, and asks first when any would go. The arrow keys move the selection, `Shift` with them adds to it, and the
left and right arrows close and open a folder.

## Colour labels

Right-click a row and pick a chip from the **Label** strip. The tag tints the item's
glyph.

**A folder hands its colour down.** A row with no tag of its own wears the colour of the
nearest tagged folder above it. An explicit tag always wins over an inherited one.

The square in the search well filters by colour: pick a colour to narrow the tree to the items
wearing it, and the neutral chip to show everything.

## Proxies

A **proxy** is a smaller copy that keeps previews fast. Attach one from **Proxy** on the
row's menu: **Set proxy…** points at a file you already have, **Make proxy** transcodes one in the
background, **Use proxy** decides whether this item reads from it, and **Clear proxy**
forgets it. A row reading from its proxy wears a `proxy` badge.

The proxies mark on the bottom bar is the master switch for the whole project, between using
proxies and using originals, and an export reads the originals whatever it is set to. See
[Proxies](/use/proxies/).

## Missing files

If a file moves, its row has a `missing` badge and the glyph turns to a broken link. The
badge *is* the relink control: click it and pick the new path, and every layer using the
item recovers. **Find missing footage** on the row menu searches for it instead.

**Replace footage…** on the row menu points a footage item whose file is not missing at a
different file. **Show in folder** opens the folder the file is in. **Interpret ▸ Interpret
footage…** sets how the file is read, see [Importing](/use/importing/#interpretation).
**Transcribe** writes down what is said in the file, and **Remove transcript** lets it go,
see [Captions](/use/captions/#transcripts).

The count at the right of the bottom bar reads `1 missing · 10 items` when anything is
broken, and clicking it filters the tree down to the broken rows alone.
