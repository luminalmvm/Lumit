The Project panel holds all imported footage, compositions, and other layers created.

| Item | What it is |
| --- | --- |
| **Footage item** | A reference to a media file on disk. |
| **Audio item** | A reference to an audio file on disk. |
| **Composition** | Compositions can be used as footage and contain other elements within them. |
| **Folder** | Used for grouping items within the project panel. |
| **Solid** | A solid colour. |


<Shot file="project-panel.png" caption="The Project panel, holding footage, a folder and a composition." eager/>

## The Header

When you select an item, if there's additional infomation it will display it here.
This includes: filename, type, resolution, frame rate, and duration.

## New composition

The panel carries a **New composition** button. Additionally if you drag footage onto 
it the dialogue will match the footage's resolution, framerate, and length.

:::note[Note yet built]
Begin able to re-interpret the footage you imported is planned. This includes properties such as :
frame rate, alpha, and colour space. See [Importing media](/use/importing/).
:::
