The **Hierarchy** panel draws the active composition as an indented tree of its layers,
top to bottom. Use it to see what a comp contains without opening anything.

<Shot file="hierarchy.png" caption="The Hierarchy panel, with a precomp twirled open." eager/>

No default workspace carries it. Switch it on from **Window ▸ Hierarchy**, or find it by
name in the command palette.

## Precomps expand

A [Precomp layer](/use/compositions/) can be opened to view the layers of the composition
nested within. Those rows carry a `precomp` tag at the right.

## What clicking does

| Gesture | Result |
| --- | --- |
| Click a row | Select that layer. |
| `Ctrl`+click | Add or remove it from the selection. |
| Click the twirl arrow | Show or hide what a precomp contains. |
| Double-click a precomp row | Front that composition in the Viewer and Timeline. |

Selection is shared with the Timeline, so a layer selected here is selected there, and the
whole selection is drawn rather than only the last row clicked.

## Read-only

The panel is for navigation. Renaming, reordering and deleting stay in the [Timeline](/panels/timeline/).

The indented tree is the whole of the panel. A second view drawing the same nesting as a
graph was designed and is not built.
