The Timeline has two halves: the **outline** on the left and **lane** or **graph** view on the right.


<Shot file="timeline.png" caption="The Timeline: outline on the left, lanes on the right." eager/>

## The ruler

| Item | What it is |
| --- | --- |
| **Work area** | Area that plays/exports. Ends are adjustable, defaults to length of composition. |
| **Markers ribbon** | Composition markers. |
| **Layer markers** | Markers that sit directly on a layer. |
| **Beat markers** | Markers placed by **Composition ▸ Detect beats**. |
| **Cache bar** | Which frames are cached, changes depending on tier. |

## The outline columns

<Shot file="timeline-outline.png" caption="The outline columns." eager/>

Left to right:

1. **Visibility · audio · solo · lock · shy**
2. **Twirl · label colour · layer number · layer name**
3. **Collapse · Flow · effects bypass · motion blur · 3D**
4. **Matte · blend mode · Parent**
5. **Render times**

## The switches

| Switch | Does |
| --- | --- |
| **Visible** | Whether the layer draws. |
| **Audible** | Whether its audio plays. |
| **Solo** | Draws only solo-ed layers. |
| **Lock** | Prevents edits to a layer. |
| **Shy** | Hide the row when the shy filter is on. Doesn't alter if the layer draws. |
| **Collapse** | On a Precomp layer, render through rather than flatten first. |
| **Flow** | Enables Flow, our optical flow synthesis. |
| **Effects bypass** | When toggled, draws layer without any effects applied to it. |
| **Motion blur** | Applies motion blur to the layer based on it's keyframed values. |
| **3D** | Makes the layer 3D and can interact with a [camera](/use/camera/). |

## The lanes

<Shot file="timeline-lanes.png" caption="A layer twirled open, showing its properties and keyframes." />

Each layer has a bar in the lane area showing when it renders. Drag the bar to move it, and drag either end to trim.

Twirl a layer open in the outline. Transform, masks and effects will appear here, along with flow options or paint 
strokes if applied.

A [Sequence layer](/use/sequence-layers/) displays its clips on one row, and is unique in how it behaves in the timeline.

## Snapping

Dragged layers and keyframes snap to whole frames.

## Render times

The stopwatch switch on the Timeline's bottom strip enables measuring render times. Each layer's row shows the entire 
render time for that layer in milliseconds for the last measured frame, each effect's heading shows the render time for that
effect, and the column header carries the entire frame's render time.
A Precomp layer's number includes everything inside it.
