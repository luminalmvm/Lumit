An icon set is a folder of SVG files, one per icon, each named after the icon it replaces.
A set can replace one icon or all of them.

## Your own icons

**Settings ▸ Appearance ▸ Custom icons** shows the folder: `%APPDATA%\lumit\icons` on
Windows and `~/.config/lumit/icons` on macOS and Linux. A `razor.svg` in it replaces the
Razor icon everywhere it appears. The row counts how many icons the folder replaces. Lumit
reads the folder again when its window comes back to the front.

## Drawing one

```xml
<svg viewBox="0 0 16 16" fill="none" stroke="currentColor" stroke-width="1.5"
     stroke-linecap="round" stroke-linejoin="round">
  <path d="M4 2.5v11l9.5-5.5z"/>
</svg>
```

- Lumit's icons are drawn on a 16 by 16 grid with a 1.5 stroke. Any `viewBox` works.
- An icon is drawn in one colour, the colour of wherever it sits, and changes with hover
  and selection like the words beside it.
- **Icon set** in Settings draws the strokes thinner or heavier by changing
  `stroke-width="1.5"`. Other widths are left as they are.

Lumit's own icons are in the repository at `flutter_ui/tool/icons/glyphs.json`, each as the
inside of a 16 by 16 SVG.

:::note
An SVG's own colours are not kept.
:::

## The names

Case, spaces and hyphens are ignored: `direct-select.svg`, `directSelect.svg` and
`Direct select.svg` replace the same icon. The older names, such as `pointer.svg` for
`select`, still work.

`null-layer`, `rounded-rectangle`, `wireframe` and `zoom-extent`.

## In a style or an extension

A style names a folder of its own icons with `--icons: url("icons");`, beside the style's
file. An [extension](/make/extensions/) carries one with `"icons": "icons"` in its
`extension.json`, and it is chosen under **Settings ▸ Appearance ▸ Icon set ▸ From
extensions**.

Of the three, the **Custom icons** folder wins, then the set chosen from an extension, then
the style's.
