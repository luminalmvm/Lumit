---
title: What you can make
description: The kinds of things anyone can make for Lumit, and where each one is explained.
---

| Kind | What it is |
| --- | --- |
| [Extension](/make/extensions/) | A folder that adds a panel or effects |
| [Theme](/make/themes/) | A colour scheme and a style, written like CSS |
| [Icon set](/make/icons/) | A folder of SVG files replacing Lumit's icons |
| [Package](/make/share/) | One `.lfx` file holding an extension, to share |
