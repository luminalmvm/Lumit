The walkthrough below will teach you how to go from an empty project through to exporting. 
Each step links to the doc page that has more specific details.

## 1. Make a composition

<Shot file="new-composition.png" caption="The dialogue for a new composition." eager/>

A **composition** is a timeline with a fixed resolution, frame rate, and duration. 
Everything you create will be based inside at least one of these.

1. Choose **Composition ▸ New composition**.
2. Set the resolution, frame rate, and duration.
3. Confirm.

See [Compositions](/use/compositions/).

## 2. Bring in your media

Import the files you plan to use. They appear in the Project panel as **assets**.

1. Choose **File ▸ Import media**.
2. Select one or more files.

Lumit never modifies files you import. The project stores a reference to the file.

See [Importing media](/use/importing/).

## 3. Add a layer

Drag an asset from the Project panel onto the timeline. It becomes a **layer**.

Each item occupies it's own layer, and items at the top appear on-top of the layers 
below them. Layers like solids, shapes, text, etc. that don't come from imported 
media can also be added to the composition.

See [Layers](/use/layers/).

## 4. Move it

Every layer has transform properties. It holds information such as the anchor point 
and position, along with scale, rotation and opacity. Twirl the layer open in the 
timeline to see the transform row, and twirl that to view each individual property.

See [Transforming layers](/use/transform/).

## 5. Animate it

<Shot file="keyframes-stopwatch.png" caption="The stopwatch beside Position, turned on, with two keyframes on the row." />

Turn on the stopwatch beside a property. From then on, Lumit records a **keyframe**
whenever you change the value at a new time.

1. Turn on the stopwatch beside Position.
2. Move the playhead to where you want a new keyframe.
3. Set the new value in the property's row in the timeline, or effect controls. 
  Transform properties like position or scale, you can do these directly in the 
  viewer too.

See [Keyframes](/use/keyframes/), and then [the graph editor](/use/graph-editor/) for
shaping the motion between them.

## 6. Watch it back

Press play or the spacebar. The cache bar under the time ruler
shows which frames are cached and currently ready for playback.

See [Preview and playback](/use/preview/).

## 7. Export it

<Shot file="export.png" caption="The export settings." />

Choose **File ▸ Export**. The interface is not blocked while an export runs, so you can
carry on working as Lumit writes the file.

See [Exporting](/use/export/).
