The [node graph](/use/nodes/) can make a parameter follow something else in the
composition, and let one effect hand its work to another. These are controlled through **wires**.

<Shot file="graph-panel.png" caption="A layer's chain with a Wiggle driver wired into Glow's Threshold." eager/>

Open the graph from **Window ▸ Panels ▸ Node graph**, or switch to the **Nodes** workspace. It
follows whichever layer is selected in the Timeline.

## Make a glow pulse with the music

The composition has a music layer and a layer you want to react to it.

**1. Put a Glow on the layer.** Select the layer and add **Effect ▸ Stylise ▸ Glow**. It appears
in the graph as a box between Source and Layer out.

**2. Add the driver.** Click empty canvas and press `Ctrl+Space`. This brings up the
effect console. Type `audio` and pick **[Audio level](/effects/drivers/audio-level/)**.

**3. Point it at the sound.** With the Audio level box picked, set **Source** to **Layer**
in the Node panel and choose the sound layer on its **Audio** row.

**4. Expose Glow's parameters.** Click the **twirl** in Glow's header and a socket
appears beside every one of its parameters.

**5. Fit the range.** Press `Ctrl+Space` again and add a **[Remap](/effects/drivers/remap/)**.
Drag from Audio level's **Low** socket to Remap's **Value** socket, then set **In high**
to about `0.4` and **Out low** / **Out high** to the quiet and loud ends of the glow you
want.

**6. Wire to output.** Drag from Remap's output to Glow's **Intensity** socket. Play the
composition back.

The Intensity row in [Effect controls](/panels/effect-controls/) now reads **driven**.
Any keyframes it had are overridden while the wire is there, and come back when it is
removed.

## Feed one effect's points into another

The points family produces a **stream**, a set of positions, and another effect reads it.

**1. Add the producer.** On a layer, add **Effect ▸ Points ▸ Grid**. It draws a lattice
of soft discs, and hands out the same lattice's points on a **Points** socket.

**2. Add the consumer, below it.** Add **Effect ▸ Points ▸ Clone to points**. It arrives
wired to Grid: its **Points** row in Effect controls reads Grid.

**3. Choose what gets cloned.** Set **Clone layer** on Clone to points to the layer you
want stamped at each point.

**4. Hide the lattice.** Turn Grid's **Mix** down to zero. The stream is still handed out.

**5. Read another producer.** Add **Effect ▸ Points ▸ Scatter** and drag its heading above
Clone to points in Effect controls. Pick it on Clone to points' **Points** row, or in the
Node graph drag a wire from its **Points** socket to Clone to points' **Points** socket.

[Connect points](/effects/points/connect-points/),
[Trail](/effects/points/trail/), [Scatter](/effects/points/scatter/) and
[Emit from image](/effects/points/emit-from-image/) feed or read the same socket.
