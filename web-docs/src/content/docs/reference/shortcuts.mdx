The shortcuts Lumit ships with, in the groups **Settings ▸ Shortcuts** lists them under.
Every one can be changed there. See [Settings](/use/settings/#shortcuts).

<Shot file="customise-keyboard.png" caption="The keyboard on the Shortcuts page. Filled keys work anywhere, outlined ones in one panel." eager/>

`Ctrl` is written for Windows and Linux. On macOS it is `⌘`, `Alt` is `⌥` and `Shift` is
`⇧`. `Numpad` keys are on the number pad. The number pad's `+`, `-` and `.` count as the
main keys of the same name.

## Where a shortcut works

- **Anywhere** works in every panel.
- A panel's own group works while that panel is the active one, and takes a key from
  **Anywhere** there. As shipped, `L` in the Timeline and `I`, `O`, `,`, `.`, `B`, `N`,
  `Ctrl+K` and `Ctrl+Shift+K` in the Cut timeline are taken this way.
- **Tools** and **Panels** work in every panel, on keys the active panel and **Anywhere**
  have not taken.
- The **Timeline** group also works in the Audio timeline. The **Cut timeline** group also
  works in a Viewer showing a source view.

No shortcut runs while a text field has the keyboard or a dialogue is open.
