A **marker** is a labelled point on a composition or a layer. Comp markers draw as small
flags on the Timeline ruler; layer markers draw on the layer's own bar and move with it.

<Shot file="markers-ruler.png" caption="Comp markers and beat markers on the Timeline ruler." eager/>

Each frame holds one marker at most. Adding a marker where one exists replaces it, and 
dragging a marker on top of another does the same.

## Add, move, edit

| Action | How |
| --- | --- |
| Add at the playhead | **Composition ▸ Add marker at playhead**, or `*`, `Shift+NUMBER`, or `Shift+M` |
| Move | Drag the marker along the ruler |
| Rename or delete | Right-click the flag: *Edit marker…* or *Delete marker* |

## Numbered markers

1. Press `Shift+0`–`Shift+9` to set that numbered marker at the playhead. Pressing the
   shortcut again moves it to the current playhead.
2. Press the bare digit `0`–`9` to jump to that marker. Nothing happens until it has
   been set, if you edit the marker's contents this will stop working for that marker.

## Beat markers

**Beat markers** are markers generated by audio onset detection. On a comp with audio:

- **Composition ▸ Detect beats** analyses the comp's audio and writes beat markers.
- **Composition ▸ Clear beat markers** removes only the generated ones.

Detection runs in the background. Where a comp carries no audio, nothing happens.

A beat marker stays a beat marker once you drag it or rename it.

Sensitivity tuning is planned, and so is tapping beats by hand during playback.
