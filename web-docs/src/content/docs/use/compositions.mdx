A **composition** is a timeline with a fixed resolution, frame rate, and duration. 
It holds an ordered stack of [layers](/use/layers/).

<Shot file="new-composition.png" caption="The new composition dialogue." eager/>

One project can have multiple compositions. A composition is an asset, so it sits in 
the Project panel.

## Make a composition

1. Choose **Composition ▸ New composition**.
2. Set the resolution, frame rate, and duration.
3. Confirm.

## Change the settings

Choose **Composition ▸ Composition settings**. Any of these settings can be changed at
any time. Additionally right clicking a composition in the Timeline, or Project panel
brings up a popup menu with the composition settings as an option.

Changing the frame rate does not move your layers or keyframes. However if you change to
a value which would make these offset from always lining up with composition frames, and
snapping is still enabled, the next time you move them, they will move to align with the
new framerate.

## Nest one composition in another

A composition used as a layer inside another is a **Precomp layer**. The verb is
**precompose**.

Precompose when you want to:

- Treat a group of layers as one object.
- Apply one effect to several layers at once.
- Retime a whole group of layers together.

Select the layers and choose **Layer ▸ Precompose**. The shortcut by default is **ctrl+shift+c**.

A Precomp layer supports [Retime](/use/retime/), so the speed of a nested
composition can be ramped.

Lumit refuses to place a composition inside itself to prevent circular references.
