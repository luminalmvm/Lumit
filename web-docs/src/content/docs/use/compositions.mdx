A **composition** is a timeline with a fixed resolution, frame rate, and duration. 
It holds an ordered stack of [layers](/use/layers/).

<Shot file="new-composition.png" caption="The new composition dialogue." eager/>

One project can have multiple compositions. A composition is an asset, so it sits in 
the Project panel.

## Make a composition

1. Choose **Composition ▸ New composition**.
2. Set the resolution, frame rate, and duration.
3. Confirm.

## Change the settings

Choose **Composition ▸ Composition settings**. Any of these settings can be changed at
any time. Additionally, right-clicking a composition in the Timeline or Project panel
brings up a popup menu with the composition settings as an option.

Changing the frame rate does not move your layers or keyframes. If they no longer line up
with composition frames and snapping is enabled, the next time you move them they will
align with the new frame rate.

## Nest one composition in another

A composition used as a layer inside another is a **Precomp layer**. The verb is
**precompose**.

Precompose when you want to:

- Treat a group of layers as one object.
- Apply one effect to several layers at once.
- Retime a whole group of layers together.

Select the layers and choose **Layer ▸ Precompose**. The shortcut by default is `Ctrl+Shift+C`.

A Precomp layer supports [Retime](/use/retime/), so the speed of a nested
composition can be ramped.

A composition holds a layer stack or a [node graph](/use/node-graphs/), never both.
**Composition ▸ New node graph** makes the second kind. It nests the same way: as a
Precomp layer in another composition, and as a Read box in another node graph.

Lumit refuses to place a composition inside itself.

## The flowchart

The flowchart draws the open composition between the compositions it is used in, on the
left, and the compositions it contains, on the right. Press `Tab`, or choose
**Composition ▸ Flowchart**. It opens at the pointer.

| Gesture | Result |
| --- | --- |
| Click a composition, or press `Enter` | Front that composition. |
| Arrow keys | Move between compositions. |
| Arrow past a composition with a stub, or click the stub | Move the chart along to that composition. |
| `Tab`, `Esc`, or a click outside | Close the flowchart. |

`Tab` opens the flowchart only while no control has focus.
