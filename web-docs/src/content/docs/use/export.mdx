**Export** writes a composition out as a file. One dialogue collects the settings, and a
queue does the writing.

## Export a composition

<Shot file="export.png" caption="The export dialogue, on the Output tab." eager/>

1. Front the composition, or select it in the Project panel.
2. Choose **File ▸ Export**, or press `Ctrl+Alt+M`.
3. Pick a preset, or set the fields yourself.
4. Choose where to write with **Browse**.
5. Press **EXPORT**.

**Composition ▸ Add to export queue** (`Ctrl+M`) opens the same dialogue. The difference
is which button you press at the end of it: **EXPORT** sets the queue running, **Add to
queue** leaves the item waiting for you to start it.

## One page, and the tabs say where you are

The dialogue is a single scrolling page. The tab row at the top — **Output**, **Time**,
**Picture**, **Colour**, **Audio**, **Metadata** — follows whichever section you have
scrolled to, and clicking a tab scrolls that section into view.

| Section | What it holds |
| --- | --- |
| **Output** | Video, image sequence or audio only; the format; where to write; and whether to make a noise or open the folder when it finishes. |
| **Composition** | Quality, resolution, whether effects and solo switches are honoured, proxies, guide layers, the disk cache and colour depth. Part of the Output tab. |
| **Time** | The span, the frame rate, and overrides for motion blur and Retime blend. |
| **Picture** | Channels and alpha, depth, bit rate, resize, crop, and the resampler. |
| **Colour** | The space the file is written and tagged in. |
| **Audio** | Whether sound is written, at what sample rate, sample width, channel layout and bit rate. |
| **Metadata** | Title, author, copyright, comment and created, plus any field of your own. |

The frame rate starts as the composition's own; the span starts as the work area where one
is set and the whole composition where it is not.

The footer states what pressing the button would produce — frames, length, size, rate, and
an estimate of the file. When a setting is one the format cannot carry, the footer says so
there instead, and both buttons go quiet until it is fixed.

## Presets

A **preset** is the whole settings payload under a name: picking one fills in every section
at once.

| Preset | What it is |
| --- | --- |
| **Master** | The composition's own frame and rate, HEVC at a worked-out bit rate, everything on. What you export when the file is for you. |
| **YouTube 1080p60** | 1920×1080, H.264, 16 Mb/s target. |
| **YouTube 1440p60** | 2560×1440, HEVC, 25 Mb/s target. |
| **YouTube 4K60** | 3840×2160, HEVC, 45 Mb/s target. |
| **Vertical 1080×1920p60** | H.264 for shorts and reels. |

Those five ship with Lumit and cannot be changed. **Save as…** stores the settings in
force under a name of your own; **Edit** renames the one showing, and offers to delete it.
Your presets live with the application rather than with the project.

**Set as default** remembers the preset and format showing as what the dialogue opens on
next time. Where exports are written lives in **Edit ▸ Settings ▸ Export**: ask each time,
beside the project, or always the same folder, with a filename template.

## What each format can hold

The engine decides. A control the chosen format cannot honour is drawn **disabled**
rather than left out or left live, so a setting never quietly does nothing.

| Format | Picture | Sound | Alpha | Depth | Bit rate | Colour space | Metadata |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **H.264 (.mp4)** | Yes | Yes | No | 8 bit | Yes | Stated in the file | Yes |
| **HEVC (.mp4)** | Yes | Yes | No | 8 bit | Yes | Stated in the file | Yes |
| **PNG sequence** | Yes | No | Yes | 8 or 16 bit | No | None stated | No |
| **TIFF sequence** | Yes | No | Yes | 8 or 16 bit | No | None stated | No |
| **M4A (AAC)** | No | Yes | — | 16 bit | Yes | — | Yes |
| **WAV** | No | Yes | — | 16 or 24 bit | No | — | Yes |

An image sequence writes one numbered file per frame beside the name you chose. A sequence
has no container to carry metadata, which is why that whole section is dead for one.

## Audio only

The third chip on the Output row writes sound and no picture — the composition's finished
mix as an M4A or a WAV. Everything to do with the picture goes dead, and the Audio
section is where the work is: 44.1, 48 or 96 kHz; 16 bit, or 24 for the uncompressed
forms; stereo, or the finished stereo mix folded down to mono once.

## Colour space

The Colour section names the space the file is written and tagged in: sRGB / Rec. 709,
Linear, Rec. 709, Rec. 2020 or Display P3. A container that can state its space says which
one in its own header; a still sequence, which states none, is offered only the space an
untagged file is taken to be.

Where the project names a colour configuration, that configuration's own output spaces
appear under a heading of their own. A file written through one of those is left
**untagged** rather than mis-tagged. A space the configuration cannot actually deliver is
listed and dead, with the reason on hover.

An export asking for a space this build cannot transform to is refused rather than written
wrongly.

## The render settings

Two rows in the Composition group decide what the export reads rather than how it is
encoded, and both default to the delivery answer whatever the project is set to:

- **Proxies** — *Use no proxies*. See [Proxies](/use/proxies/).
- **Guide layers** — *All off*.

**Motion blur** and **Retime blend** in the Time section are overrides on the export's own
throwaway copy of the composition: leave them at *Current settings* to get what you see,
or force them off for a fast check. Neither touches the project.

## The queue

<Shot file="export-queue.png" caption="The export queue, with one composition waiting."/>

Both buttons put the item in the queue, and the queue window opens on top. **Window ▸
Export queue** reopens it later.

One export runs at a time and the rest wait. Each row says which composition it came
from, what it is writing, and how it is getting on — *Waiting*, the frame it is on and the
encoder writing it, *Done*, or the failure in the engine's own words. **START** sets a
stopped queue running.

- **Drag a waiting row** to move it up or down. The order of the list is the order they
  run in; a row that is running, has run, or has failed cannot be picked up.
- **The × on a row** cancels it while it is writing, and forgets it once it has stopped.

An item is photographed the moment it is queued, so it goes on writing what you asked for
however much you change the project afterwards.

## Export does not block, and it does not cut corners

Export runs apart from the interface, so you can carry on editing while it writes. The
status strip at the bottom of the window says which frame it is on, and carries a Cancel
that works whether the queue window is open or not.

[Adaptive degradation](/use/preview/) and preview resolution touch the preview alone: an
export always runs at the quality the dialogue asks for.

:::note[Not built yet]
ProRes and DNxHR intermediate codecs are not offered, and there is no export priority
control. OCIO is the one face in the dialogue drawn dead in this build: the **Managed by**
row reads back the configuration the project names and cannot be set from here.
:::
