**Export** renders your work and provides you with an output file(s).

## Export a composition

1. Select the composition.
2. Choose **File ▸ Export**, or press `Ctrl+Alt+M`.
3. Set the format, preset, range and destination.
4. Start it.

The dialogue exports one composition at a time.

## Export doesn't block

Export runs apart from the interface. You can carry on editing while it writes.

## Presets

| Preset | For |
| --- | --- |
| **YouTube 1080p60** | H.264, high bitrate. |
| **YouTube 1440p60** | HEVC; the scene's quality trick. |
| **Vertical 1080×1920** | Shorts, TikTok, Reels. |
| **PNG sequence** | One lossless still per frame, with alpha. |

## Codecs and encoders

Video exports as **H.264** or **HEVC**. Lumit probes for a hardware encoder (NVENC, AMF
or QSV) and picks one automatically. A software fallback is always available. Audio is
AAC. A PNG sequence is lossless, and it carries no audio and no bitrate.

## Export is always full quality

[Adaptive degradation](/use/preview/) and preview resolution touch the preview alone. An
export always runs at full quality.

To go faster, an export may **bake** internally, flattening retimes, rasterising and
pre-compositing. Baking happens inside the export pipeline, and your project is never
altered by it.

:::note[Not built yet]
An export queue, where several items are lined up with their own range, preset and
filename, is planned but not built. So are ProRes and DNxHR intermediate codecs, free
width and height (sizes are preset-driven today), and an export priority control.
:::
