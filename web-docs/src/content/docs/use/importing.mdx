Everything you import becomes an **asset** in the Project panel. An asset that points
at a media file is a **footage item**.

Imported footage never modifies the original file. The project references the files path,
as well as how to interpret what it finds there.

## Import files

1. Choose **File ▸ Import**.
2. Select one or more files.

Dragging files from your file manager onto the Project panel works as well.

## Organise the panel

Use **folders** to group assets. A folder groups assets in the panel and nothing more;
it does not create folders on your computer.

## Interpretation

Frame rate and alpha are read from the file itself. So is the colour space, and Lumit
uses what it finds.

:::note[Not built yet]
Overriding the interpreted values is planned. Currently there is no way to do this.
:::

## Missing files

If a file moves, the asset reports that it is missing. Relink it to the new path and
every layer using it recovers.

## Proxies

A **proxy** is a smaller stand-in for a footage item that keeps preview fast. Generation
happens in the background, and because the toggle is global, a proxy never reaches your
export.

:::note[Not built yet]
Proxies are planned; none of this exists in Lumit today.
:::

## After Effects projects

A whole After Effects project can be imported via **File ▸ Import ▸ After Effects project**.
This will attempt to import the entire project, with support for all compositions, markers, 
layers, keyframes, and built-in effects. 3rd part effects currently won't be imported, but
won't affect the rest of the project being imported.
