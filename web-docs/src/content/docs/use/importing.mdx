Everything you import becomes an **asset** in the Project panel. An asset that points
at a media file is a **footage item**.

Imported footage never modifies the original file. The project references the file's path,
as well as how to interpret what it finds there.

## Import files

1. Choose **File ▸ Import footage…**, `Ctrl+I` by default.
2. Select one or more files.

Dragging files from your file manager onto the Lumit window works as well, and so do
**Import footage** on the [Project panel](/panels/project/#bringing-things-in)'s bottom
bar and a double-click on the panel's empty space. An empty editor offers **Import
footage** beside **Open**.

**File ▸ Import folder…** imports the footage in a folder and every folder inside it. Each
folder becomes a project folder of the same name. Hidden files and folders are left out.

Everything picked at once is one undo step. While the files are read, a card shows how far
the import has got, with **Cancel import**, which leaves the project as it was. One import
runs at a time.

## What Lumit opens

The dialogue's **Footage** filter lists the common formats: MP4, MOV, MKV, AVI, WebM,
M4V, MPEG, TS, MTS, M2TS, WMV, FLV, 3GP, OGV, MXF and GIF; PNG, JPEG, TIFF, OpenEXR, HDR,
Targa, DPX, BMP, WebP, PSD, AI and the Netpbm family; WAV, MP3, FLAC, AAC, M4A, OGG, Opus, AIFF
and WMA; and the 3D models glTF, GLB, FBX and OBJ, plus OpenVDB volumes, Blender, USD, Alembic, PLY, STL and
Collada files.

The filter is a convenience, not a limit. Switch it to **All files** and pick anything -
Lumit reads the file rather than its extension, so a container or codec the list does not
name opens if the build can decode it. A file the build cannot decode still imports as an
item; it never gets a picture on its row, and the row wears an `unreadable` badge.

## Organise the panel

Use **folders** to group assets. A folder groups assets in the panel and nothing more;
it does not create folders on your computer.

## Image sequences

Pick any one file of a folder of numbered stills and the whole run imports as a single
footage item. See [Image sequences](/use/image-sequences/).

## Photoshop documents

A `.psd` with two or more layers imports as a composition the size of the document, with
one layer for each Photoshop layer. Each layer is also a footage item, filed in a folder
named after the file.

- Name, opacity, visibility and blend mode are kept.
- A top-level group becomes a layer group. A group inside a group, or one with its own
  opacity or blend mode, becomes a composition of its own and a Precomp layer.
- A layer mask and a clipping mask are applied to the layer's picture.
- A vector mask becomes masks on the layer, unless Photoshop has already drawn it into the
  layer's picture.
- A layer with no picture is left out, and the bottom strip says how many were.
- A solid colour fill layer becomes a Solid layer.
- Drop shadow, inner shadow, outer glow, inner glow, colour overlay and stroke become
  layer styles.
- An Invert, Posterize, Threshold, Brightness/Contrast, Exposure, Hue/Saturation, Levels,
  Curves, Black and White, Vibrance, Colour Balance or Photo Filter adjustment layer
  becomes an Adjustment layer carrying the nearest effect. It arrives switched off, since
  the same numbers give a different picture in Lumit. Switch it on and set it by eye.
- A 16 bit document keeps its depth.

:::note[Not built yet]
The other adjustment layers, a Vibrance below zero, a Curves drawn freehand or with more
than sixteen points, a Photo Filter whose colour isn't stored as Lab, gradient and pattern
fills, and the other layer styles are not imported. A group's own mask and styles are
dropped. PSB, 32 bit, CMYK, Lab and indexed documents are not split into layers.
Affinity files are not read.
:::

## Illustrator documents

An `.ai` with two or more top-level layers imports as a composition the size of the first
artboard, with one layer for each Illustrator layer. Each layer is also a footage item,
filed in a folder named after the file. An `.ai` with one layer imports as a single
footage item.

- Name and visibility are kept.
- A layer's opacity, blend mode, clipping masks and effects are drawn into its picture.
- Sublayers are drawn as part of the top-level layer they are in.
- A point in Illustrator is a pixel in Lumit.

**Layer ▸ Create ▸ Shapes from vector layer** makes a [shape layer](/use/shapes/) of a
layer's paths, one group per path, and switches the layer off. **Split into shape layers**
makes one shape layer per path. Gradients come across as flat grey, and clipping masks,
placed pictures and text are left out.

Lumit reads the PDF copy of the artwork that Illustrator saves with **Create PDF
Compatible File** switched on. A file saved with it off imports as the page of text
Illustrator writes in the artwork's place.

:::note[Not built yet]
A layer is read as pixels at the artboard's size, and softens when scaled past 100%. Only
the first artboard is read. Sublayers are not split out. Files from before Illustrator 9
are not read.
:::

## 3D models

A glTF, GLB, FBX or OBJ file imports as a **3D model** footage item, with the cube on its
row. Its `.bin`, pictures and `.mtl` are found beside it, or by name in the folders next to
it, and are packed with it. Dropped into a comp it makes a **Model layer** at the centre and
opens **Model settings**: **Up axis**, **Fit to comp**, and **Units**, the comp pixels for
each metre of the model, greyed while it is fitted. **Layer ▸ 3D ▸ Model settings** opens it again. In a comp with no
lights, the first model also adds an **Ambient light** and a **Key light**.

A `.vdb` file imports the same way and draws through [Smoke and
fire](/effects/generate/smoke-and-fire/).

A Model layer is drawn through the comp's camera with the file's own materials, lit by the
comp's lights, and passes through other 3D layers by depth. Its effects run on its
picture, which keeps its depth. Motion blur smears it along its own movement. In the
Viewer it is outlined by its box and picked where the model itself is. A model with
pictures missing wears a `missing` badge in the Project panel, with their names on its
tooltip.

Under **Materials** a Model layer has a group of rows for each material in its file, named
as the file names it, in the Timeline and in **Effect controls**: **Base colour**,
**Metallic**, **Roughness**, **Emission colour**, **Emission strength**, **Opacity**,
**Normal strength**, **Textures**, **Transmission**, **IOR**, **Coat** and **Coat
roughness**. They start at the file's own values, keyframe like any other row, and are kept
on the layer, never in the file. **Textures** off leaves out the file's base colour and
metal-rough pictures. **Base colour layer**, **Emission layer**, **Opacity layer** and
**Normal layer** each take a layer of the comp as the picture on the model's own uvs. A
Normal layer is read as a normal map saved to a PNG would be.
**Projected from** names a Camera layer, and the Base colour layer is then read where that
camera saw each point, not on the model's uvs. Where the camera can't see a point, behind it,
outside its frame or hidden by another model on the same camera, the point keeps **Base
colour**. **Projection time** is **Follow**, which moves with the playhead, or **Hold**, which
stops the camera and the picture at **Hold frame**, and picking Hold starts it at the playhead.
Under Hold the picture stays on a model that moves. A point its camera saw at a steep angle
fades to Base colour once it is seen much more square-on. A projected point takes the shadows
of other models and no light, with **Accepts shadows** Only or **Holdout** too.
**Layer ▸ 3D ▸ Project from camera** sets every material of the selected Model layers at once: the
selected Camera layer or the comp's own, or a new one when the comp has none, and the shot that
camera was solved from, the selected picture, or the nearest picture below. A still holds at
the playhead and anything else follows it. A row on a 3D layer can't be projected. **Layer
▸ New ▸ Card** makes a flat Model layer with no file, filling the frame, for any plane.
Transmission bends the comp's picture behind the model, softened by Roughness and tinted by
Base colour. Under an environment light, metal, glass and Coat reflect it. In a view's
**Shaded** look glass shows what is behind it without bending it, and **Normals** draws it
solid. A material's menu has **Presets** (Chrome, Gold, Brushed metal, Glass, Frosted
glass, Plastic, Rubber, Emissive, and any saved), **Save preset…** and **Reset**, which puts
the file's values back. A preset starts from the file's values and turns Textures off.

A `.blend`, USD (`.usd`, `.usdz`, `.usdc`, `.usda`), Alembic (`.abc`), PLY, STL or Collada
(`.dae`) file opens through your own Blender, which turns it into a glTF in the cache. Its row
wears a `converting` badge until then; click it to stop Blender, and click `stopped` to
start again.
An FBX Lumit can't read goes the same way. Saving the file again converts it again, and the
layer keeps the old model until the new one is ready, or if it won't convert. Objects hidden in
Blender are left out. With no Blender found the row wears `no 3D app`; click it to choose
one in [Settings](/use/settings/#general). Blender 5 and later have no Collada importer. Two Blenders
run at once, and the rest wait.
**Edit in 3D app**, under **Layer ▸ 3D** and on the item's right-click menu, opens a `.blend` in
Blender.

A new Model layer casts shadows, on itself, on other models and on 3D layers, and takes
theirs. Its **Casts shadows** and **Accepts shadows** rows work as on any 3D layer, and
**Holdout** draws what is under it in its place (see [Layers](/use/layers/)).

A file with takes shows an **Animation** group on its layer. **Take** picks one by name, and
a new layer starts on the first. A take the file has lost reads as **(missing)** and draws at
rest. **Offset** moves it in seconds. The layer's
[Retime](/use/retime/) times it, as it times footage. **Loop** says what happens past its
ends:

| Loop | Past the ends of the take |
| --- | --- |
| **Off** | The model rests as its file has it |
| **Loop** | The take goes round |
| **Mirror** | The take runs there and back |
| **Freeze** | The first and last poses hold |

Skins and morph targets from glTF and FBX are drawn, and motion blur, shadows and the outline
follow them. A skin that names a joint the file doesn't have draws at rest and wears
**Missing**, as does a model too large for the graphics card to pose. A model that
[Smoke and fire](/effects/generate/smoke-and-fire/) comes from or goes round holds the pose its
take starts in.

**Parts** on the layer lists the file's nodes as a tree. Each part has a tick that hides it and
what hangs from it, and a **Transform** heading over **Visible**, **Position**, **Rotation**
and **Scale**, in the layer's pixels and axes, turning about the part's own origin. They key
like any row. A part with nothing changed isn't saved. Hiding a bone shrinks what it moves to
its origin. A mesh on a skin has only the tick. Double-clicking the model in the Viewer opens
the part under the pointer, the bone that moves it on a skin.

A picked part wears a thin box and the 3D handles at its pivot. A drag moves it, or turns it
with the Rotation tool, along the layer's axes, in one undo step. Shift keeps a move to steps
of 10 and a turn to steps of 15 degrees.

**Layer ▸ 3D ▸ Create cameras and lights** makes a Camera or Light layer for each one in the file,
keyed over the layer's span, in one undo step, with Zoom keyed where an FBX or a `.blend` moves
the lens. They follow the model at the time, and don't change if it changes later. Lights made
this way take the place of the **Key light** the first model brought, if it hasn't been changed.

:::note[Not built yet]
A projected point has no row to take the comp's light, and what its camera didn't see can't be
left clear for a second projection to fill. Under **Hold** a model's take plays on under the
picture, which doesn't stick to what moves, and a projected model's take doesn't blur with
motion.
A faded model's shadow doesn't fade, and a holdout's outline doesn't blur with motion.
Expressions can't name a part's rows. FBX in-between shapes use the final shape. An
orthographic camera gets the default lens. A glTF file's lens doesn't animate. A particle
shape or emitter surface from a model stays at rest. Materials don't change the shadow a
model casts, so glass casts a whole shadow, and they don't reach a model used as a particle's
shape. Glass does not bend the model itself, and shadows and haze from 3D layers below a 2D
layer don't reach a run with glass in it.
:::

## Interpretation

Frame rate and alpha are read from the file itself, and so is the colour space.

A recording with a variable frame rate, as screen and game captures often are, is laid out
at its average rate: each frame shows the picture that was on screen at that moment, so the
picture stays with its sound. A stretch recorded slower repeats frames and one recorded
faster skips some.

**Interpret footage…** on a footage row's menu changes how the file is read. It opens on
every selected footage item at once.

| Setting | Does |
| --- | --- |
| **Render pass** | Which pass of a multi-pass EXR is shown. **Auto** picks the beauty pass. Cryptomatte passes are not listed. |
| **Alpha** | Straight, premultiplied against a matte colour, or ignored. **Guess** reads it from the file's frames. |
| **Invert alpha** | Swaps opaque and clear. |
| **Frame rate** | Plays the file's frames at another rate. The picture gets longer or shorter and its sound does not. *From file* in the list goes back to the file's own rate. |
| **Start timecode** | The timecode of the first frame, which the source view counts from. |
| **Separate fields** | Splits each interlaced frame into its two fields, at twice the rate. *Off*, *Upper field first* or *Lower field first*. The order the file declares is shown beside it as *From file*. |
| **Preserve edges** | Fills a field's missing rows along the edges in the picture. |
| **Remove pulldown** | Takes a 3:2 or 24Pa cadence out of interlaced video, at one of five phases each. **Guess** finds the cadence. Disabled while fields are not separated. |
| **Pixel aspect ratio** | Widens or narrows the picture until its pixels are square. The list holds *Square pixels*, the D1/DV, HDV, DVCPRO HD and anamorphic 2:1 shapes, and the file's own as *From file*. |
| **Loop** | Plays the picture through more than once, up to 9999 times. |
| **Colour space** | What the file arrived in, see [Colour management](/use/colour-management/). |
| **Linear light** | Whether the file's numbers are already linear: *On*, *Off*, or *Automatic*, which is on for a floating-point file and off for any other. Read only with no colour space chosen. |
| **Preserve RGB** | Takes the file's numbers as they are, with no colour conversion. |

The dialogue has two tabs. **Main** holds the render pass and the groups **Alpha**,
**Time**, **Fields and pulldown** and **Other**, and **Colour** holds the last three rows
of the table. A **Guess** that finds nothing reads *Nothing to go on*.

An EXR pass of one channel, such as depth, shows in grey at the values the file holds.

**Remember interpretation** on the same menu keeps one item's settings, and **Apply
interpretation** gives them to every selected item. What is remembered lasts
until Lumit closes.

While the Project panel is the active panel, `Ctrl+Alt+G` opens **Interpret footage…** on
the selected footage, `Ctrl+Alt+C` remembers and `Ctrl+Alt+V` applies.

Footage from an After Effects project keeps the interpretation it had there, opened
directly or through a Lumit Bridge bundle. Its OCIO colour space comes across from an
opened `.aep`, and an ICC colour profile, which Lumit can't use, is named in the import
report. A project colour managed with OCIO opens with the same config, and one After
Effects ships is found in its install.

:::note[Not built yet]
A proxy is not read while fields are separated. A looped item's sound plays once. The
fields and pixel aspect ratio a file declares are shown and not applied until chosen.
:::

## Missing files

The project file keeps each footage path relative to itself. Footage on another drive keeps
its full path. When the project opens, each file is looked for at its relative path, then
at the full path it last had, then by its content under the project's folder.

If a file moves, the asset reports that it is missing. Relink it to the new path and
every layer using it recovers. Other missing items whose files moved the same way are
relinked with it.

Until then the item's layers draw colour bars, its row in the
[Project panel](/panels/project/#missing-files) wears a `missing` badge, and the
[Viewer](/panels/viewer/) counts the missing files.

## Proxies

A **proxy** is a smaller copy of a footage item that keeps preview fast, made or
attached from the footage row's own menu. Exports read the originals unless you ask them
not to. See [Proxies](/use/proxies/).

## Lumit projects

Picking a `.lum` in the import dialogue opens **Import a composition**, which lists its
compositions. The one chosen is added to the project, with everything it uses. A `.lum`
dragged onto the window is not imported.

- The compositions nested in it, its solids and its footage come with it. Footage the open
  project already has is used again.
- Where the open project already has a composition of the same name, the new one has the
  other project's name after it in brackets.
- The whole import is one undo step.

## Lottie files

A Lottie (`.json`) or dotLottie (`.lottie`) picked in the import dialogue, or dropped on the
window, becomes a composition. Its precomps arrive as compositions in a folder named after
the file, and its pictures are written beside the file in a folder named after it. The
**Import report** lists what didn't come across. See
[Lottie and SVG](/use/lottie-and-svg/#import-a-lottie).

## After Effects projects

A whole After Effects project can be imported via **File ▸ Import .aep
project…**, with support for compositions, markers, layers, keyframes, and built-in
effects. It takes an `.aep`, or a zipped [Lumit Bridge](#lumit-bridge) bundle. A text layer
keeps its font, spacing, outline, alignment, and box width. A
light keeps its type, its aim and its light options, and a 3D layer its Orientation,
Anchor Z, Scale Z and material options, keyframes included. A 3D layer, camera or light
turns its X, Y and Z Rotation in After Effects' order.

The import makes a new project in place of the open one. For a step-by-step guide, see
[Bringing in an After Effects project](/tutorials/after-effects-import/).

A common third-party effect becomes the maker's own OFX plugin where one is installed, with
its controls carried across by name. Any other third-party effect arrives as a placeholder
that keeps its values and draws nothing. Neither stops the rest of the project importing.

**Remove Grain** arrives as [Denoise](/effects/blur-sharpen/denoise/). Temporal filtering
sets **Frames** to 2, or to 0 when it is off. Its amount becomes **Temporal strength**, and
the blend with the original becomes **Mix**. Nothing else comes across, the noise samples
included: select the effect and press **Learn**.

A Warp Stabilizer becomes a [Stabilise](/use/stabilising/#from-after-effects).

Expressions come across as JavaScript and run as written, and a pseudo effect arrives as
[Custom controls](/effects/controls/custom-controls/). A property with both keyframes and
an expression keeps its keyframes. See
[Expressions](/use/expressions/#what-javascript-can-read).

Essential Graphics come across as a [graphics template](/use/graphics-templates/#from-after-effects):
a composition's controllers as its controls, and a precomp layer's Essential Properties as its
copy's values. A Dropdown Menu Control arrives as a Custom controls menu.

Animation presets (`.ffx`) are imported from **Settings ▸ General ▸ After Effects
presets**. See [Effects & presets](/panels/effects-presets/#after-effects-presets).

### The import report

**Import report** opens when the import ends. It lists what did not come across whole,
under a heading for each outcome with its count: **Skipped** first, then **Placeholder**,
then **Adjusted**. Its foot counts the items imported. With nothing to list it reads
*Everything imported*. The report is shown once, and the new project has no file until it
is saved.

| Outcome | Meaning |
| --- | --- |
| **Skipped** | Could not be brought across. |
| **Placeholder** | Kept in its place with all its values, and changes nothing in the picture. |
| **Adjusted** | Came across with a difference, which the line states. |

Lines that say the same thing are one line with a count. A click on it lists where it
applies: the composition, layer or effect. A right-click on a line has **Show where**,
**Show where for all**, **Copy line**, **Copy where** and **Copy report**. **Copy report**
at the foot copies the whole report as text.

### What comes across differently

| In After Effects | In Lumit |
| --- | --- |
| A shape operator Lumit has not got, such as Merge Paths or Zig Zag | Left out. The shape draws without it. |
| Wiggle Paths, Offset Paths | The nearest Lumit modifier. |
| A keyed fill or stroke colour, opacity or width, or a keyed group opacity | Kept as it starts. |
| A gradient's colours | White to black. |
| A Text or Shape layer's extrusion depth and bevel | Geometry options. |
| Text animators, text on a path, tsume, a justified last line, source text that changes | Not imported. The text is. |
| Audio layer | A Footage layer carrying its sound. Separate left and right levels become the left one. |
| A layer kind Lumit has not got, or a layer whose source is gone | A Null layer, in the same place. |
| Time stretch | The equivalent [Retime](/use/retime/). |
| Pixel Motion frame blending | Flow frame interpolation. The in-between frames differ. |
| Classic blend modes | Their modern counterparts. A blend mode Lumit has not got becomes Normal. |
| Preserve underlying transparency, draft layer quality | Not applied. |
| Keyed Casts Shadows or Accepts Shadows | The first key's setting. |
| A light kind Lumit has not got | The nearest kind. |
| A motion path's spatial tangents | Not carried. Each axis animates on its own. |
| Mask feather that differs in x and y | One feather, their average. |
| RotoBezier mask | The polygon through its points. |
| Pixel aspect ratio other than square | Square pixels. |
| A composition's start timecode | The composition starts at zero. |
| Preserve frame rate, or resolution, when nested | Nested compositions follow the one they are in. |
| An expression Lumit cannot run | Switched off, with its text kept. The keyframes under it drive the property. |
| A built-in effect Lumit has no match for | A placeholder that keeps every parameter. |
| A third-party effect | The same effect, when it is installed as an [OFX plugin](/use/plugins/). Otherwise the closest Lumit effect at its defaults, or a placeholder. |
| Footage that is not on this computer | A missing item with its interpretation kept. |
| A project at 8 bits a channel without linear blending | Blended in scene-linear light. Blends can shift. |

### Lumit Bridge

An `.aep` that Lumit cannot read is not imported, and the open project stays. Where only
its structure cannot be read, its footage comes in alone, with no compositions or layers.

Lumit Bridge reads such a project from inside After Effects. It is `lumit-bridge.jsx`, in
`tools/ae-bridge` of Lumit's source, and runs in After Effects 2024 or later. It writes the
open project out as a folder ending `.lum-bundle`, and Lumit imports a zip of that folder.

- The bundle records where the footage is and does not hold the files.
- Values that After Effects scripts cannot read, such as the points of a Curves effect, are
  not in a bundle. The import report lists them.
- A bundle written by a newer Lumit Bridge than Lumit knows is refused.
