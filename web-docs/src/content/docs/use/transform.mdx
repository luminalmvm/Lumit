Each layer has transform properties. Twirl the layer open in the Timeline to reach them, or
work in the Viewer with the tools and the selected layer's gizmo.

<Shot file="transform.png" caption="A layer's transform properties in the Timeline." eager/>

## The properties

| Property | What it does |
| --- | --- |
| **Anchor point** | The point the layer scales and rotates around. |
| **Position** | Where the anchor point sits within the composition. |
| **Scale** | Size, as a percentage. |
| **Rotation** | Angle, in degrees. |
| **Orientation** | A 3D layer's turn, as in After Effects: three angles outside X, Y and Z Rotation, moving between keys by the shortest turn. |
| **Opacity** | How opaque a layer is, as a percentage. |

On a 3D layer Anchor point and Scale have a z too. Scale z stretches what is parented to the
layer along its depth, and how far Anchor point z pushes the layer itself.

Right-click a 3D layer's rotation rows for **After Effects rotation order**: X, Y and Z
Rotation turn in After Effects' order, as an imported layer's do. Changing it keeps the layer
where it is.

Every property can be animated. See [Keyframes](/use/keyframes/).

## Separate axes

Anchor point, position and scale are each one row with a value box per axis. Right-click
the row's name for **Separate axes**, and each axis gets a row of its own with its own
keyframes. **Combine axes** on the same menu puts them back, with Scale linked.

Scale's menu also carries **Link axes** and **Unlink axes**:
linked, one edit scales both by the same factor; unlinked, each box is edited on its own.

## Move the anchor point

Use the anchor point tool in the Viewer to move it without moving the layer, or drag the
anchor point directly with the selection tool.

## The gizmo

Select a layer and the Viewer draws its wireframe and a transform gizmo. Drag the handles
to move, scale, and rotate.

Hold `Shift` to keep a move to one axis, or a scale in proportion. The arrow keys nudge the
selected layers one pixel, or ten with `Shift`. See [the Viewer](/panels/viewer/#moving-a-layer).

## Parenting

Parent a layer to another and it follows the parent's transform. Its own values then read
as offsets from the parent. Parenting or unparenting a layer does not move it on the
current frame. A 3D layer, camera or light keeps its X, Y and Z Rotation; the turn goes on
its Orientation.

The Viewer draws a parented layer's outline, handles and motion path through the whole parent
chain. Drags, nudges and **Align** move its Position in the parent's space.

Use a **null layer** as the parent when you want a rig that never draws. One layer can
parent many layers at once.
