A **script** is a JavaScript file that edits the open project. After Effects scripts
(`.jsx`) run as they are.

## Run one

1. Choose **File ▸ Run script…**.
2. Pick the `.js` or `.jsx` file.

While it runs, a card covers the window with the script's name and **Stop**. A file the
script asks for opens the system file dialogue, and a message it shows appears in the
status line.

The whole run is one undo step, named after the file. A script that fails or is stopped
leaves the project as it was.

When a script fails, the status line gives the reason and the line it failed on.

## After Effects scripts

| Object | What works |
| --- | --- |
| `app` | `project`, `newProject()`, `beginUndoGroup()`, `endUndoGroup()` |
| `app.project` | `items`, `numItems`, `item()`, `rootFolder`, `file`, `importFile()`, `save()` |
| `items` | `addFolder()`, `addComp()`, `length`, `[n]` |
| Any item | `name`, `parentFolder`, `comment` |
| `CompItem` | `width`, `height`, `duration`, `frameRate`, `frameDuration`, `pixelAspect`, `numLayers`, `layer()`, `layers`, `openInViewer()` |
| `layers` | `addCamera()`, `addNull()`, `add()` of footage, `byName()`, `length`, `[n]` |
| Any layer | `name`, `index`, `enabled`, `guideLayer`, `threeDLayer`, `shy`, `solo`, `locked`, `motionBlur`, `startTime`, `inPoint`, `outPoint`, `parent`, `setParentWithJump()`, `autoOrient`, `moveToBeginning()`, `moveToEnd()`, `moveBefore()`, `moveAfter()`, `remove()`, `property()`, `transform` |
| Properties | Anchor Point, Position, Scale, Orientation, X, Y and Z Rotation, Opacity, and a camera's Point of Interest, Zoom, Focus Distance and Aperture, by match name or by name |
| Keys | `value`, `valueAtTime()`, `setValue()`, `setValueAtTime()`, `setValuesAtTimes()`, `addKey()`, `removeKey()`, `numKeys`, `keyTime()`, `keyValue()`, `setInterpolationTypeAtKey()` |
| `FootageItem` | `mainSource.conformFrameRate`, `file`, `duration` |
| `ImportOptions` | `file`, `sequence`, footage as `importAs` |
| `File`, `Folder` | `$.fileName`, `name`, `fsName`, `parent`, `exists`, `getFiles()`, `open()`, `read()`, `readln()`, `File.openDialog()` |
| Globals | `alert()`, `$.writeln()`, `writeLn()`, `AutoOrientType`, `KeyframeInterpolationType`, `ImportAsType` |

Anything else stops the script with a message naming it.

### Where Lumit differs

- Keys are linear or hold. A Bezier key comes in as linear, and ease and curved motion
  paths are not carried.
- Key times land on the nearest frame of the comp.
- A 3D layer's X, Y and Z Rotation are turned into Lumit's rotation order. The layer
  matches After Effects on every key.
- Orientation is set once. Keys on it stop the script.
- A layer given a `parent` stays where it is at the comp's start.
- `app.newProject()` answers the open project.
- A numbered still always imports as the whole sequence.
- A footage item's `duration` is known once it has a layer.
- An item's `comment` and a comp's pixel aspect are not kept.
- `#target` lines are skipped. `#include` stops the script.
- A script reads and lists files in its own folder and the folders inside it, and files you
  chose or passed to it. A script at the top of a drive or in the home folder itself has no
  folder of its own. Anywhere else `exists` is false.
- A script imports footage only from the files it can read. It saves the project over its own
  file or as a new `.lum` file, and exports, only into the project's folder or its own, never
  over a file.
- A network path or a device is refused.
