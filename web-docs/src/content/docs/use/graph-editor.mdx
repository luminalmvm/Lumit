The graph editor draws a property as a line of value, or rate of change, against time.

<Shot file="graph-editor.png" caption="The graph editor, showing the value graph." eager/>

## The three views

| View | Shows |
| --- | --- |
| **Value graph** | The value against time. |
| **Speed graph** | The rate of change against time. |
| **Acceleration graph** | How fast the speed changes, in the property's unit per second squared. |

All three show the same underlying data. Editing one affects the others. **Value**,
**Speed** and **Acceleration** at the bottom of the graph editor switch between them.

The scope button at the bottom steps through **Selected curves**, **Layer curves** and
**Composition curves**: the selected properties, every animated property of the selected
layers, or every animated property in the composition. Unselected curves are dashed; click
one to select it, or `Shift`-click or `Ctrl`-click to add it.

## Edit a curve

- Drag a keyframe to change its value and time.
- Drag a handle to change the curve's shape.
- Hold `Alt` as a handle drag begins to move that handle without its partner, or to join two
  that were apart.
- **Join handles**, on a keyframe's right-click menu, joins handles that were apart.
- Turn on **Break handles** at the bottom of the graph editor to move one handle at a time
  with no key held. It is off each time Lumit starts.
- Select several keyframes to move them together. Dragging a handle on one moves the same
  handle on each by the same amount.

To change a keyframe to linear, easy ease, or hold, press **Linear**, **Easy ease** or
**Hold** at the bottom of the graph editor. The default shortcut for easy ease is `F9`.
**Easing…**, on the value graph only, opens the easing editor. **Auto**, **Clamp** and
**Free** set the selected keyframes' tangents.

In the easing editor, a click on a shape applies it. Once a shape is saved, the shapes sit
in two tabs, **Built in** and **Yours**. Drag the two handles and press **Apply** for a
shape of your own: `Shift` snaps a handle, `Alt` mirrors the other one. The buttons under
the curve are **Read from keys**, which takes the shape of two selected keyframes,
**Reverse**, **Apply as you shape** and **Save…**. Right-click the curve to copy it as
`cubic-bezier()` or paste one.

Right-click a keyframe for **Linear**, **Easy ease**, **Hold**, **Keyframe speed…**, **Copy
ease**, **Paste ease**, **Join handles** and **Delete key**. Paste ease is listed once an ease
has been copied.

**Edit ▸ Settings ▸ Shortcuts ▸ Dragging** changes `Alt` to `Ctrl`.

In the acceleration graph each keyframe has an in dot and an out dot. Dragging a dot up or
down changes that side's influence and keeps its speed, as far as the influence can reach.
Dragging it sideways moves the keyframe in time.

## Retime in the graph editor

A Retime curve opens on the value graph. With **Edit ▸ Settings ▸ Timeline ▸ Editing ▸
Retime opens to Speed** on, it opens on the speed graph. See [Retiming and speed](/use/retime/).
