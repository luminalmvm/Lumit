The graph editor draws a property as a line of value, or rate of change, against time.

<Shot file="graph-editor.png" caption="The graph editor, showing the value graph." eager/>

## The two views

| View | Shows |
| --- | --- |
| **Value graph** | The value against time. |
| **Speed graph** | The rate of change against time. |

Both views show the same underlying data. Editing either affects the other.

## Edit a curve

- Drag a keyframe to change its value and time.
- Drag a handle to change the curve's shape.
- Select several keyframes to move them together.

To change a keyframe between linear, bezier, or hold, press the relevant button at the 
bottom of the graph editor. The default shortcut to switch to bezier is `F9`.

## Retime in the graph editor

Retime keyframes can be displayed differently depending on your preference.

If you are familiar with After Effects' time remapping then using the default setting is
likely the best, it displays the layers exact time value which you can then alter as normal.

If you are more comfortable with Vegas' velocity, then you can toggle **Edit ▸ Settings ▸ 
Interface ▸ Retime opens in Speed**. This alters the retime graph to open and displays with 
speed as the y axis, as a percent. By default this will be is 100% for a layer, but you can 
edit this as you want, and even make the retime speed negative.

For more infomation, see [Retiming and speed](/use/retime/).
