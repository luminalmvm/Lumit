Press **Ctrl+Space**, **Cmd+Space** on macOS, and the effects console opens at the pointer:
a search row, a strip of categories, the matching rows, and a line saying what choosing a
row does.

## The search

The search box reads **Search effects and compositions**, with the key that opened the
console at its right. Typing narrows the list. The letters only have to appear in order, so
`db` finds Directional blur.

| Key | Does |
| --- | --- |
| **Up** and **Down** | Move the highlight |
| **Enter** | Run the highlighted row |
| **Escape** | Clear the search, then close the console |

A click on a row runs it. A click outside closes the console.

## What it lists

The strip narrows the list to **All** or to one group. Each row sits under its group's
heading.

| Rows | Choosing one |
| --- | --- |
| Effects, by category | Applies the effect to the selected layer |
| **Presets** | Applies the saved preset to the selected layer |
| **Node graphs** | Applies the graph to the selected layer as the [Node graph](/effects/utility/node-graph/) effect |
| **Compositions** | Opens the composition in the Timeline |

Drivers are filed under **Controls**. Compositions come after every effect, preset and node
graph that matches. The composition being edited is not offered under Node graphs.

The line at the foot reads **Enter applies to the selected layer**. With several layers
selected, only the primary layer gets it. With none selected, nothing is applied.

## Over a graph

With a graph canvas focused, **Ctrl+Space** opens the same console with the graph's own
list; see [The node graph](/use/nodes/) and
[Node graph compositions](/use/node-graphs/#the-console). The foot reads
**Adds a box to the graph**, or with a wire in hand **Connects the dragged wire where it
fits**.

## The snapshot button

The camera button, **Save snapshot**, saves the frame on screen as a PNG, in a `Snapshots`
folder beside the saved project, or in `Pictures\Lumit` if the project has never been
saved. It is greyed with no composition open.

## Not the command palette

**Ctrl+Shift+P** opens the command palette. The palette is *every command by name*;
the console is effects, presets, node graphs and compositions.
