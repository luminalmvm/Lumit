An **addon** is an optional download: the model runtime, or a model pack. Each pack reads
your footage and hands back one thing: an in-between frame, a depth map, a matte, the outline
of what you clicked, the words said, or the voice in a recording. They run on your own
machine. Lumit works without any of them.

<Shot file="models-installed.png" caption="Settings ▸ Addons with the runtime and all five packs installed." eager/>

## What each one is for

| Addon | Size | What it makes | Used by |
| --- | --- | --- | --- |
| **Model runtime** | | Nothing on its own. Every pack needs it. | All of them |
| **RIFE 4.9** | 20 MB | The frame between two real ones. | [Flow](#flow-rife) |
| **Depth Anything V2 Small** | 94 MB | A depth map from a single frame. | [Depth](#depth) |
| **Robust Video Matting** | 14 MB | A matte for a person, carried frame to frame. | [Remove background](#remove-background) |
| **BiRefNet Lite** | 214 MB | A matte for the main subject of a frame. | [Remove background](#remove-background) |
| **SAM 2.1 Hiera Tiny** | 111 MB | The outline of the thing you click on. | [Roto brush](#roto-brush) |
| **Whisper large-v3 turbo** | 1.1 GB | The words said, when, and who says them. | [Captions](#captions-whisper) |
| **Whisper small** | 280 MB | The same from a smaller model, which can also write it in English. | [Captions](#captions-whisper) |
| **DeepFilterNet3** | 8 MB | The speech in a recording, apart from everything else. | [Voice isolation](#voice-isolation) |

Every addon is an analysis model. Nothing generative is listed.

## Install them

**1. Open Edit ▸ Settings… ▸ Addons.** Nothing is installed yet.

**2. Press Check for addons.** Lumit fetches the catalogue. This button is the only time it
looks. Each pack lists its licence and size, and reads **Needs the runtime** until the
runtime is in.

<Shot file="models-catalogue.png" caption="The catalogue, before the runtime is installed."/>

**3. Install the Model runtime.** Press **Install** on its row.

**4. Install the packs you want.** Each download is checked against its published hash
before Lumit uses it.

One addon installs at a time. A download shows a bar and **Cancel**. A pack already
installed at another version reads **Update**.

The runtime loads the first time an effect asks for it. The line under its row then names
the graphics provider it is running on and its version, or reads **Installed. Would not
load.** with the reason.

An installed pack's row gives its licence, its size and its job: **Depth**, **Matte**,
**Segmentation** or **Frame synthesis**.

**Install from file** installs a pack from an `addon.json` with its files beside it, for a
machine with no network. **Where they are kept ▸ Show** opens the folder. **Remove** on a
row deletes that addon. **Licence** opens its licence in the browser.

An install or a removal takes effect at once. An install that fails says why under the
**Catalogue** row:

| Line | Means |
| --- | --- |
| **Lumit could not reach the download.** | The catalogue or a file could not be fetched. |
| **The list of addons could not be read.** | The catalogue is not one this version reads. |
| **That addon description could not be read.** | The `addon.json` is unreadable, or its files are not beside it. |
| **This addon has nothing for this machine.** | It is published for other platforms only. |
| **The download did not arrive whole.** | A file is not the published length. Nothing is installed. |
| **The download is not the file that was published.** | A file does not match its published hash. Nothing is installed. |
| **Another addon is installing.** | A second install was asked for. |
| **That addon could not be installed.** | The install was turned down, or there is nowhere to keep it. |
| **That addon could not be removed.** | A runtime that has loaded stays in use until Lumit is restarted. |

## Without a pack

- An effect that needs a pack wears **This effect needs an addon that is not installed**,
  names the pack beneath, and passes its picture, or its sound, through unchanged.
- The Flow group, the Roto brush and the export dialogue show **Open addons**, which opens
  the Addons page.
- An installed addon whose files are gone or the wrong size reads **Files are missing** and
  does not run.

## Where they are used

### Flow: RIFE

[Flow](/use/retime/#frames-in-between) makes the frames between real ones when a layer is
slowed down. Turn it on with the **Flow** switch in the layer's **Modes** column, or
**Layer ▸ Flow**, then set **Engine** in its **Flow** group to **RIFE**.

<Clip name="addons-rife" caption="Engine set to RIFE on a shot slowed to 25%, then played through."/>

The Flow group is in the layer's rows in the Timeline, and in Effect controls while
**Settings ▸ Timeline ▸ Transform in Effect controls** is on.

A machine without RIFE previews the layer with the built-in engine and says so on the row.
An export of that layer is **refused**.

### Depth

**Effect ▸ Utility ▸ [Depth](/effects/utility/depth/)**, then **Analyse**. The shot is read
once, in the background, and nearer is brighter.

<Shot file="models-depth.jpg" caption="Depth on the whole shot, read by DirectML."/>

Point a [Depth of field](/effects/blur-sharpen/depth-of-field/)'s Matte row, a **Set matte**
or a track matte at the layer to use it.

### Remove background

**Effect ▸ Utility ▸ [Remove background](/effects/utility/remove-background/)**, then
**Analyse**. **Model** picks the pack:

- **Robust Video Matting** for a person in video. **Detail** sets **Portrait** or **Full
  body**.
- **BiRefNet** for the main subject, whatever it is, a frame at a time.

<Shot file="models-remove-background.jpg" caption="Remove background with BiRefNet, and the Model list open."/>

**View** shows the cut-out or the matte. Another layer reads the matte through its Matte
row, a **Set matte** or a track matte.

### Roto brush

Set **Seed from** on the [Roto brush](/effects/utility/roto-brush/) to **Segment**. Pick the
**Roto brush** tool (`Alt+W`) and click the subject on the base frame. Each click refines
the outline, and `Alt`-click marks what is not the subject. Then press **Propagate**.

<Shot file="models-roto.jpg" caption="Three clicks on the runner, propagated through the shot. View is Boundary."/>

Without SAM 2.1, a propagation seeded by **Segment** is **refused**.

### Captions: Whisper

[Create captions](/use/captions/#make-captions) hears speech with a Whisper pack. Both packs
hear about a hundred languages, tell voices apart and find where speech starts and stops.
With both installed, **Whisper large-v3 turbo** is used, and **Whisper small** for **Into
English**.

### Voice isolation

**Effect ▸ Audio ▸ [Voice isolation](/effects/audio/voice-isolation/)** keeps the speech in
a layer's sound and turns everything else down. The model runs on the processor. Without
DeepFilterNet3 the sound plays untouched, in an export too.

## Licences

Each pack keeps its own licence, named on its row. BiRefNet's weights are trained on
DIS5K, whose terms are non-commercial.
