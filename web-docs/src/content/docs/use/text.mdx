A **Text layer** holds editable text.

<Shot file="text-layer.png" caption="A text layer being edited in the Viewer." eager/>

## Add text

1. Pick the Type tool.
2. Click in the Viewer.
3. Type.

## Style it

Set the font, size, letter-spacing, fill colour, and stroke.

A text layer is a layer, so it also takes [effects](/use/effects/),
[masks](/use/masks/), and a [transform](/use/transform/) like any other.

:::note[Limitation]
A text layer styling currently cannot be applied on a per character basis. 
Mixed styling within a single layer is planned.
:::

## Run it along a path

A line of type can follow one of the layer's **own masks**.

1. With the text layer selected, draw a path on it with the pen. Leave its mode as **None**
   if you only want the curve — that mode is geometry and gates nothing.
2. In the **Source** section of Effect Controls, set **Path** to that mask.

**Path offset** appears beside it and slides the whole line along the curve, in pixels — the
same unit the curve is measured in, so *20 px along* means the same thing on a circle and on
a scrawl. A closed path wraps, so a ring of type runs round for ever. An open one drops the
letters that fall off either end, which is what running out of curve should look like.

The mask stays an ordinary mask: drag its points, keyframe it, and the words follow. Deleting
it lays the line straight again and the row reads *Missing mask* — a deleted mask never empties
a layer.

:::note[Limitation]
The Source rows are not keyable, so the path offset holds one value. Animating a line along a
curve waits on that.
:::

## Animators

An **animator** offsets the letters of a line, and a **range selector** says which letters it
reaches. Sweeping the range over time is the cascade every title sequence is made of.

**Add animator**, at the foot of the **Animators** section in Effect Controls, gives you one
with every row already there, defaulted to values that change nothing.

| Row | What it does |
| --- | --- |
| **Range start**, **Range end** | Where the stretch of letters begins and ends, as a per cent of the line. |
| **Range offset** | How far the whole stretch is slid along. Keyframing this is what makes a cascade. |
| **Based on** | Whether the range counts **Characters** or **Words**, so a word's letters can move together. |
| **Shape** | **Square** — inside the range or not — or **Ramp**, rising evenly across the range and holding past its end. |
| **Position**, **Rotation**, **Scale**, **Opacity** | What a letter the range reaches does. |
| **Fill offset** | Three numbers added to the layer's fill colour, so a letter can tint one way or the other. |

A letter half inside the range gets half the offset. A letter turns about its own middle on
the baseline, not about the pen point, so tall letters do not swing out of the line — and
everything an animator does happens inside the letter's own frame, so a line on a path is
pushed along and away from the curve rather than across the picture.

Several animators on one layer **compose**: pushes, turns and tints add, scales and opacities
multiply. That is what lets a fade animator and a drop animator be written separately and
still read as "and also". It is also why the colour row is an offset rather than a second
colour — a replacement cannot compose.

An animated line is given one text size of room a side so a letter can drop in from above.
A letter thrown further than that is clipped at the layer's edge.

## Convert it

**Layer ▸ Create** turns a selected text layer into something else, as a **copy directly
above it**. The original stays a text layer, still typeable, still keyed.

- **Shapes from text** makes a [shape layer](/use/shapes/) of the letters' outlines. They are
  real curves taken from the font, as editable as anything drawn with the pen, and a counter
  — the ring of an `o`, the eyes of an `8` — comes out as a hole. The copy lands on the words
  it came from, path and all. Its masks and paint do not come across, because both are
  measured from a corner that has moved.
- **Points from text** makes a copy that emits a stream of points in the shape of the words,
  through [Emit from image](/effects/generate/emit-from-image/) reading the layer's own
  picture. A word as a thinning crowd in the shape of itself, rather than a wire frame of its
  outline.

Both are one undo step, and both are offered only on a text layer. A line with no ink in it —
empty, or only spaces — refuses rather than leaving an empty layer behind.

:::note[Not built yet]
Converting a *styled* line, per-character layers, and creating masks from text are all the
same outline walk with a different destination, and none of them is built.
:::
