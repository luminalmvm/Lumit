A **Text layer** holds editable text.

<Shot file="text-layer.png" caption="A text layer being edited in the Viewer." eager/>

## Add text

1. Pick the Type tool.
2. Click in the Viewer.
3. Type.

## Style it

Set the font, size, letter-spacing, fill colour, and stroke.

A text layer is a layer, so it also takes [effects](/use/effects/),
[masks](/use/masks/), and a [transform](/use/transform/) like any other.

:::note[Limitation]
A text layer styling currently cannot be applied on a per character basis. 
Mixed styling within a single layer is planned.
:::
