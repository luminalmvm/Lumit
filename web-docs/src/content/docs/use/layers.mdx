Compositions hold an ordered stack of **layers**. Layers draw from the bottom up, meaning 
the top layer composites over everything below it.

## Add a layer

- Drag an asset from the Project panel into the timeline.
- Or choose **Layer ▸ New** and pick the type of layer you need.

## The layer kinds

| Kind | What it is |
| --- | --- |
| **Footage layer** | One footage item as a source. Supports [Retime](/use/retime/). |
| **Solid layer** | A flat colour. Often used as a base for effects. |
| **Precomp layer** | Another composition, used as a layer. Supports Retime. |
| **[Text layer](/use/text/)** | Editable text. |
| **[Shape layer](/use/shapes/)** | Vector shapes with fills and strokes. |
| **[Sequence layer](/use/sequence-layers/)** | Similar to Footage, but allows cutting within one layer. |
| **Adjustment layer** | Invisible. Its effects apply to everything below it. |
| **Null layer** | Invisible and transform-only. Used to drive other layers. |
| **[Camera layer](/use/camera/)** | A 3D viewpoint. Affects layers with the 3D switch on. |
| **Light layer** | A source of light. Shades layers with the Accepts lights switch on. |
| **[Audio layer](/use/audio/)** | Sound with no picture. Made by placing an audio file, or by **Add audio only** on a clip that has a picture too. |

## Order and selection

Drag a layer up or down to change ordering. Select several layers to apply commands 
to all of them at once.

Selection applies across the application. For instance, picking a layer in the Viewer 
selects it everywhere.

## Copy and paste

**Edit ▸ Cut / Copy / Paste** can copy whole layers if selected and can be pasted into
other compositions as well. A copied layer retains all information: transform, keyframes, 
masks, paint, effects, switches, markers, and retime values.

By default a pasted layer starts at the playhead, but this can be changed to be the 
layer's original time in the composition, turn on *Paste layers at their original time* in
[Settings ▸ Interface](/use/settings/). A parent or matte reference is retained 
only if the target composition still contains that layer. To paste at the
copied time instead.

## Switches

<Shot file="layer-switches.png" caption="The switches on a layer's row." />

Each layer has switches in the timeline, in order above: visibility, mute, solo, lock, 
and shy, then: flow, disable effects, motion blur, and 3D.

A row shows only the switches its layer can use. An [Audio layer](/use/audio/) has no 
visibility switch, and a layer that can never be heard — a solid, text, a shape, or a clip 
with no sound — has no mute switch.

The **motion blur switch** smears a layer from it's own transformations, you'll only
notice this if you have keyframes properties on the layer. The Motion blur
effect is different, see [Effects](/use/effects/).

## Adjustment layers

An adjustment layer draws nothing of its own. Its effect stack applies to the composite
of everything below it. If you change the position or scaling of the adjustment layer, 
effects on it will only apply to the area of the viewer it covers.

## Parenting

Parent a layer to another and it inherits the parent's transform and can apply it's own
on top of them.
