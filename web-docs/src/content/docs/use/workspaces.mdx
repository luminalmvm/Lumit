Lumit's **panels** can dock, split, and float. An arrangement of panels is a **workspace**.

<Shot file="workspace.png" caption="A workspace: Viewer, Timeline, and Project docked together." eager/>

## The panels

| Panel | What it is for |
| --- | --- |
| **Viewer** | The preview, and tools that can alter items within it. |
| **Project** | Assets and folders. |
| **Timeline** | Time, layers, Graph editor, and keyframes. |
| **Effect Controls** | The selected layer's effect parameters. |
| **Effects & Presets** | Panel listing all presets and effects you have available |
| **Scopes** | Waveform and vectorscope readouts. |
| **Hierarchy** | The open comp's layers as a tree, precomps expandable. |

## Rearrange

Drag a panel's tab to move it. Drop it near an edge to split, or onto another tab group to
join it. Drag it out of the window to float it.

## Show and hide

The **Window** menu lists every panel with a tick showing whether it is currently visible. 
Toggle to add or drop a panel.

## Workspaces

There are several built-in presets (Edit, Effects, Colour, Audio). Your current
workspace persists between sessions.

:::note[Not yet built]
Custom workspaces can not currently be saved, but will persist across sessions unless you switch
workspace. These are planned.
:::

## The command palette

`Ctrl+Shift+P` opens the command palette: search for any command and run it.

## The menu bar

Nine menus: **File, Edit, Composition,
Layer, Effect, Animation, View, Window, Help**.

A menu item that requires something you have not selected appears disabled.
