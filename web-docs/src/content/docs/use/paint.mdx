**Paint** puts strokes straight onto a layer. There are three tools in the toolbar for this:

<Shot file="paint.png" caption="Brush strokes on a layer, with the Paint heading open in the Timeline." eager/>

| Tool | Does |
| --- | --- |
| **Brush** | Paints the fill colour. |
| **Clone stamp** | Copies pixels from elsewhere on the same layer. `Alt`-click sets the origin point it copies from, then paint. |
| **Eraser** | Similar to Brush, but instead makes the area of the layer the stroke covers transparent. |

Brush **size**, **shape** (round or square), **hardness**, **opacity** and **pressure**
appear in the tool options while using a paint tool.

## Pressure

With a graphics tablet, pressing harder makes a wider mark. The **Pressure** tick in the tool
options turns it on and off per brush; off commits a full press everywhere, which is the
stroke a mouse would have made. With no pen in the room nothing changes either way.

Pressure sets the **width** of the mark and nothing else. Not opacity, not colour, not
hardness — each of those is a number you set deliberately, and a pen quietly overriding one is
how a brush stops being predictable. The stroke carries the pressures it was drawn with, so
trimming it or re-rendering at any resolution keeps them.

:::note[Not built yet]
Tilt is read by nothing. Honouring it needs a brush tip that can turn, and there is no angle
in the two shapes there are; it is owed together with a shaped brush rather than faked on a
round dab.
:::

## Strokes are paths

What Lumit stores is the drag infomation (the path, colour, size, hardness, opacity), 
which is composited into the layer each time the frame renders. This means painting at
quarter-resolution preview will still export at full quality.

Strokes are composited **before masks and effects**: a mask gates the painted picture, and
effects will operate upon strokes as if they were part of the original layers source.

## Editing strokes

- A layer's strokes are listed under a **Paint** heading in the Timeline when the
  layer is twirled open.
- Each stroke is a single undo.
- An brush/clone/erase's strength can be reduced later by lowering it's opacity.
- **Start** and **End** under each stroke trim it by a percentage of its own length, and both
  are keyframable: hold Start at 0 and animate End from 0 to 100 and the stroke draws itself on.
- Each stroke picks a **blend mode** from the same list a layer does, deciding what colour the
  mark lays down. An eraser ignores it, having no colour to combine.

:::note[Limitation]
A keyframed **Start**/**End** draws its diamonds on the Timeline lane but has no curve in the
graph editor yet.
:::
