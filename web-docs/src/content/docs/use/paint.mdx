**Paint** puts strokes straight onto a layer. There are three tools in the toolbar for this:

<Shot file="paint.png" caption="Brush strokes on a layer, with the Paint heading open in the Timeline." eager/>

| Tool | Does |
| --- | --- |
| **Brush** | Paints the fill colour. |
| **Clone stamp** | Copies pixels from elsewhere on the same layer. `Alt`-click sets the origin point it copies from, then paint. |
| **Eraser** | Similar to Brush, but instead makes the area of the layer the stroke covers transparent. |

Brush **size**, **shape** (round or square), **hardness**, and **opacity** appear in the tool
options while using a paint tool.

## Strokes are paths

What Lumit stores is the drag infomation (the path, colour, size, hardness, opacity), 
which is composited into the layer each time the frame renders. This means painting at
quarter-resolution preview will still export at full quality.

Strokes are composited **before masks and effects**: a mask gates the painted picture, and
effects will operate upon strokes as if they were part of the original layers source.

## Editing strokes

- A layer's strokes are listed under a **Paint** heading in the Timeline when the
  layer is twirled open.
- Each stroke is a single undo.
- An brush/clone/erase's strength can be reduced later by lowering it's opacity.

:::note[Not built yet]
There is currently no support for drawing via tablet, so pressure and tilt are missing.
Keyframing a stroke's start and end time is not built either, nor are per-stroke blend modes.
:::
