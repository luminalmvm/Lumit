A **preset** is a saved configuration of one or more effects and their parameters. 
Keyframes will also saved along with the rest of the effect.

<Shot file="presets.png" caption="Saved presets at the top of the Effects and presets panel." eager/>

## The .lumfx file

A preset is saved as a `.lumfx` file. The Windows and macOS installers register the extension, 
so double-clicking one opens Lumit.

A preset that uses effects your copy Lumit doesn't have will still load. Unknown effects come
in as placeholders with their parameters preserved, so if you later install the effect, it will
begin to work.

## Save a preset

1. Select the layer whose effect(s) you want to keep.
2. In the Effects and presets panel, choose **Save preset…**.
3. Name the file. The save dialogue defaults to the preset library folder.

## Apply a preset

- Double-click a preset under **Saved presets** at the top of the Effects and presets
  panel. Its whole stack is applied to the selected layer.
- Or choose **Load preset…** to apply a `.lumfx` file from anywhere on disk.

:::note[]
Files saved outside the default preset library folder don't appear within the Effects and
presets panel.
:::
