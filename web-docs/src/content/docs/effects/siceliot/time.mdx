## What it does

Hands out the layer's time from its **Value** socket: the time counted in **Units**,
multiplied by **Speed**, plus **Offset**. It reads the same for every copy
[Clone to points](/effects/points/clone-to-points/) stamps.

| **Speed** | Slider | -10 to 10; any value by typing | 1 | - |
| **Offset** | Slider | -1000 to 1000; any value by typing | 0 | - |

## What each control does

- **Units**: whether it counts in seconds or in the composition's frames.
- **Speed**: how fast it counts. 2 is twice as fast, and below 0 it counts down.
- **Offset**: added after Speed, in the chosen units.
