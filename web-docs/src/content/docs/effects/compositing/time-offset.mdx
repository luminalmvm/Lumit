## What it does

Time offset shows the picture on its input socket at the current time plus **Offset**. It
is a box in a [node graph composition](/use/node-graphs/) and is not offered on a layer's
stack. Everything upstream of it is read at the shifted time, a Read of footage or of a
composition included. A layer's own retime is [Retime](/use/retime/); this shifts one
branch of a graph.

## What each control does

- **Offset**: how far in time the input is shifted, in seconds. Negative looks back.
