## What it does

Repeat end runs the boxes wired between a [Repeat start](/effects/compositing/repeat-start/)
and itself **Times** times, and shows the result. It is a box in a
[node graph composition](/use/node-graphs/) and is not offered on a layer's stack. A wire
out of the boxes between the two may only go into the Repeat end, and the graph refuses
any other. A pair may sit inside another. Each pair is drawn with a frame round it.

A graph stops adding times past 4,096 steps.

## What each control does

- **For**: **Times** runs the boxes Times times. **Each point** runs them once for each
  point on the Repeat start's **Points** socket, and **Each path** once for each path on its
  **Shapes** socket.
- **Times**: how many times the boxes run. At 0 the Repeat start's picture is shown as it
  arrived.
- **Mode**: **Feedback** runs each time on the picture the time before made. **Copies**
  runs each time on the Repeat start's picture and lays every time over the ones before
  it, the first at the bottom.
- **Blend**: how each copy is laid over the ones before it. Copies only.
