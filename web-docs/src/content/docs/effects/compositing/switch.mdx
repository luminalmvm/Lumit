## What it does

Switch shows the picture on the socket its **Index** names, counting from **in0**. It is a
box in a [node graph composition](/use/node-graphs/) and is not offered on a layer's
stack. There is always one spare socket beyond the last one wired. An unwired socket, or
an index past the last socket, shows nothing.
