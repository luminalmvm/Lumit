## What it does

Applies [Gaussian blur](/effects/blur-sharpen/gaussian-blur/) on a per channel basis.
This allows you to alter red, green, blue, and alpha channels blur separately.

In the Effect Controls panel:

- **Matte** scales how much of the effect each pixel gets: white applies it in full, black leaves the pixel as it arrived, grey part way. **Invert** reads the matte the other way round, light for dark.

## What each control does

- **Red blur**, **Green blur** and **Blue blur** set how far each colour channel
  is spread. A channel value of 0  affects nothing.
- **Alpha blur** does the same for transparency. On a layer that is opaque across
  the entire layer it does nothing if repeat edge pixels is on.
- **Repeat edge pixels**. On holds the border pixel outward. Off will blur edges 
  with a colour/alpha value of 0.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the blur amount from another layer's brightness, 
  scaled by the blur amounts you set; see [Effects](/use/effects/).

## Notes

If what you actually want is the three channels pulled *apart*, look to use
[Chromatic aberration](/effects/distortion/chromatic-aberration/) or
[RGB split](/effects/distortion/rgb-split/).
