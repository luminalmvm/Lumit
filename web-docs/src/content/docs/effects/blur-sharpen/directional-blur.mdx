## What it does

A blur along a single line. 

For a smear that follows visual motion in the footage, use
[Fast motion blur](/effects/temporal/fast-motion-blur/).

## Parameters

{/* GENERATED:parameters - rewritten by `npm run docs:effects`. Edit the prose, not this block. */}

| Parameter | Control | Range | Default | Unit |
| --- | --- | --- | --- | --- |
| **Length** | Slider | 0 to 200; higher by typing | 10 | Per cent of the composition diagonal |
| **Angle** | Slider | -180 to 180; down to -3600 and up to 3600 by typing | 0 | - |
| **Mix** | Slider | 0 to 100 | 100 | - |
| **Matte** | Layer | Any layer in the composition | None | - |
| **Invert** | Checkbox | On or off | Off | - |

In the Effect Controls panel:

- **Matte** scales how much of the effect each pixel gets: white applies it in full, black leaves the pixel as it arrived, grey part way. **Invert** reads the matte the other way round, light for dark.

{/* END GENERATED */}

## What each control does

- **Length** is the length of the blur.
- **Angle** adjusts the angle of the blur.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the blur amount from another layer's brightness, 
  scaled by the blur amounts you set; see [Effects](/use/effects/).
