## What it does

Applies an even blur across the whole image.

## Parameters

{/* GENERATED:parameters - rewritten by `npm run docs:effects`. Edit the prose, not this block. */}

| Parameter | Control | Range | Default | Unit |
| --- | --- | --- | --- | --- |
| **Radius** | Slider | 0 to 25; up to 100 by typing | 1.5 | Per cent of the composition diagonal |
| **Mix** | Slider | 0 to 100 | 100 | - |
| **Matte** | Layer | Any layer in the composition | None | - |
| **Invert** | Checkbox | On or off | Off | - |

In the Effect Controls panel:

- **Matte** scales the blur radius per pixel: white blurs at the full Radius, grey blurs narrowly, black not at all — a blur whose width varies across the frame, which a strength dissolve cannot produce. **Invert** reads the matte the other way round, light for dark.

{/* END GENERATED */}

## What each control does

- **Radius** adjusts the size of the blur.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the blur amount from another layer's brightness, 
  scaled by the blur amounts you set; see [Effects](/use/effects/).
