## What it does

It exaggerates the difference between each pixel and its 
neighbours, which crisps the image.

- **Matte** scales Amount per pixel: white sharpens by the full Amount, black not at all. **Invert** inverts the mattes for calculating strength.

## What each control does

- **Amount** changes the amount the difference from neighbours is exaggerated.
- **Radius** is how far out the four neighbours are taken.
- **Mix**: how much of the result replaces the original.
