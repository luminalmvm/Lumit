## What it does

The picture is compared against a blurred copy of itself and the difference is added back.

## What each control does

- **Amount** sets how strongly recovered detail is added back.
- **Radius** is the size of detail that gets lifted.
- **Threshold** is how different a pixel must be to be lifted.
- **Luminance only** sharpens brightness while leaving colour alone.
- **Mix**: how much of the result replaces the original.
