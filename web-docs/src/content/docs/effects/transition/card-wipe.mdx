## What it does

Transitions the layer as a grid of cards, each one turning and
disappearing. This works as a wave across the frame.

## What each control does

- **Completion** is how far from beginning to end the wipe is.
- **Transition width** sets how much of the whole wipe one card's own flip
  takes.
- **Rows** and **Columns** set how many cards there are.
- **Flip axis** chooses which line each card turns about. 
- **Flip direction** chooses which way each card turns. 
- **Flip order** sets which side the wave starts from.
- **Randomness** sets how far each card's turn is shuffled away from Flip order.
- **Seed** randomises the shuffle.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
