## What it does

Wipes the layer away along a straight line.

## What each control does

- **Wipe centre x** and **Wipe centre y** sets the line pivot centre.
- **Completion** is how far the edge has travelled as a percentage.
- **Wipe angle** sets the direction the edge runs.
- **Feather** softens the edge.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
