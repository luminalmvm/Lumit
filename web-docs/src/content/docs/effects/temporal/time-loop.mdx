## What it does

Draws the **Source layer** as it is at a moment inside the loop, with its own effects and
the drivers wired into them. The loop runs on the clock of the layer the effect is on:
from **Start**, **Duration** long. The looped picture is laid over the layer's own.

With Source layer empty, or set to the layer the effect is on, the loop is that layer as
the effects above Time loop leave it, and it takes the place of the layer's picture. The
effects below Time loop run on the looped picture.

With **Map placement** on As placed in comp, the source's transform is read at the looped
moment too, so its movement loops.

**Crossfade Bastiuni** reads the source for Duration and **Fade length** together, and
draws it twice while it fades.

## What each control does

- **Source layer**: the layer whose stretch is looped. Empty, it is the layer the effect
  is on.
- **Map placement**: where the source sits on this layer: as it sits in the composition,
  stretched over the frame, or centred at its own size.
- **Type**: how the loop comes round. **Cycle** starts again. **Ping-pong** plays forwards
  and then backwards. **Crossfade Bastiuni** fades from the source one lap later into the
  source now, over the first Fade length of each lap.
- **Start**: where the looped stretch begins, on this layer's clock.
- **Duration**: how long the looped stretch is.
- **Fade length**: how long each lap's fade lasts, up to Duration.
- **Fade curve**: **Linear** fades at an even pace. **Smooth** eases at both ends.
- **Mix**: how much of the result replaces the original.
- **Blend**: the blend mode the result is laid over the original with.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness;
  see [Effects](/use/effects/).
- **Channel**: the channel of the Matte layer that is read.
