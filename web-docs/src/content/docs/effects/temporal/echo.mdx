## What it does

Lays a run of the layer's own earlier frames over or behind the present one.

- **Matte** scales Decay per pixel: the trail dies away sooner where the matte is dark and reaches its full length where it is white, so the ghosts are genuinely shorter rather than faded back. **Invert** reads that matte inverted.

## What each control does

- **Echoes** sets how many earlier frames are displayed.
- **Decay** governs how quickly each successive echo fades.
- **Mode** says how each echo is combined into the trail. **Behind** puts each
  echo behind the ones after it; **In front** lays them over.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
