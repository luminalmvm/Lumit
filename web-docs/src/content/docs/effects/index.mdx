Every effect Lumit ships with has a page here: what it is for, and a table of
every parameter with its range, its default and its unit. The tables come
straight from the engine's own catalogue, so they cannot drift from the
application.

For applying effects, ordering a stack and using adjustment layers, see
[Effects](/use/effects/). For the panel the controls live in, see
[Effect Controls](/panels/effect-controls/).

## How to read a page

Each page opens with what the effect is for and when to reach for it, then the
parameter table, then what each control actually does. The table carries the
numbers — range, default, unit — and the prose beneath it carries the reasoning,
so the two are worth reading together rather than in place of one another.

A few conventions run through the whole catalogue:

- **Mix** appears on almost every effect. It blends the processed picture over
  the untouched one, so it is the way to ease an effect back without disturbing
  anything above it — and, being animatable, the usual way to pulse an effect on
  a beat.
- **Matte** and **Invert** appear on every effect too, and by default the matte
  is a strength: point the row at a layer, and that layer's brightness says how
  much of the effect each pixel gets — white in full, black not at all, grey
  part way, with Invert swapping which end does which. It is not the same as
  masking the effect's result, which hides what the effect already did
  everywhere; a matte feeds the effect itself, so a blur driven by one genuinely
  blurs less where the matte is dark rather than smearing and then fading back.
  A handful of effects put the matte deeper into their own maths — the blur's
  radius, the glow's seed, depth of field's focus, the flare's light sources —
  and each of those pages says so under its own table.
- **Distances** are given either as a percentage of the composition diagonal or
  in pixels at composition size, and the Unit column on each page says which.
  Both survive a resize and both match between a draft preview and the export,
  so a Quarter-resolution scrub looks like the finished frame, only softer. A
  parameter whose unit reads as a dash is a plain number and follows neither
  rule — its own page says what it counts.
- **Every parameter animates.** Turn on its stopwatch to start. See
  [Keyframes](/use/keyframes/).
- Effects that need a **file or another layer** — a LUT, a depth pass, a
  background to wrap — do nothing until you supply one, and say so rather than
  failing.
