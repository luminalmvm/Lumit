Every effect has a page here detailing information about it. Parameter details explain
each property in an effect, and almost every page has a picture comparison to allow you 
to view what the effect does.

For applying effects, ordering a stack and using adjustment layers, see
[Effects](/use/effects/) and [Effect Controls](/panels/effect-controls/).

## Page information

Effect pages open explaining their purpose. Then the parameter table, and a explaination of
what each control does.

A few conventions run through the whole catalogue:

- **Mix** appears on almost every effect. It blends the effect with the composite before
  the effect was applied. A **Blend** dropdown sits beside it with the layer blend
  modes. On Normal nothing changes; on any other mode the effect runs at full
  strength, is blended over the picture in that mode, then Mix is applied once.
- **Matte** and **Invert** appear on every effect too. A matte is an input to an effect. 
  For example a blur driven by a matte blurs less where the matte is dark, It is not
  simply the same as if you could change the opacity of an effect. Some effects use the 
  matte to drive more than just strength, in these cases the effect page explains it's use.
- **Distances** are counted in pixels. They adapt to resizes, including exporting at a
  different resolution.
- **Every parameter animates.** Turn on its stopwatch. See [Keyframes](/use/keyframes/).
- Effects that require a **file or another layer** as input do nothing until you supply one.

### Drivers

Values that other effects follow, wired up rather than keyframed.

A driver makes a number, a colour or a stream of points instead of a picture, so it has no
page picture and does nothing on its own. Drop one on a layer and run a wire from its
socket into another effect's parameter, and that parameter follows the wire instead of its
own keyframes. Bypass the driver and the parameter goes back to the keyframes it had.

See [The node graph](/use/nodes/) for how a driver is added and wired.
