Light sweep is a **Stylise** effect.

## What it does

Lays a band of light across the layer through **Centre**. The light lands only where the
layer draws.

## Parameters

| Parameter | Control | Range | Default | Unit |
| --- | --- | --- | --- | --- |
| **Centre** | Point | Any position | 960, 540 | Pixels at composition size |
| **Angle** | Dial | Any angle | 30° | Degrees |
| **Width** | Slider | 0 to 2000; any value by typing | 160 | Pixels at composition size |
| **Softness** | Slider | 0 to 100 | 60 | - |
| **Colour** | Colour | Each channel 0 to 1 | White | - |
| **Intensity** | Slider | 0 to 400; any value by typing | 100 | - |
| **Mode** | Dropdown | Add · Screen | Add | - |

## What each control does

- **Centre**: a point the band passes through.
- **Angle**: the direction across the band. At 0° the band stands upright.
- **Width**: how wide the band is.
- **Softness**: how much of the Width fades at its sides.
- **Colour**: the light's colour.
- **Intensity**: how bright the light is.
- **Mode**: how the light is laid on. **Add** can go past white, and **Screen** never does.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's
  brightness; see [Effects](/use/effects/).
