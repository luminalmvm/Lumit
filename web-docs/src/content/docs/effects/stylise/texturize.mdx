## What it does

Uses another layer as a texture to look as if the source layer has been printed on it.

## Parameters

{/* GENERATED:parameters - rewritten by `npm run docs:effects`. Edit the prose, not this block. */}

| Parameter | Control | Range | Default | Unit |
| --- | --- | --- | --- | --- |
| **Texture** | Layer | Any layer in the composition | None | - |
| **Light direction** | Dial | Any angle; snaps every 15° while a modifier is held | 45° | - |
| **Relief** | Slider | 0 to 20; higher by typing | 1 | Pixels at composition size |
| **Texture contrast** | Slider | 0 to 200; higher by typing | 100 | - |
| **Placement** | Dropdown | Stretch · Tile · Centre | Stretch | - |
| **Scale** | Slider | 10 to 400; down to 1 and higher by typing | 100 | - |
| **Mix** | Slider | 0 to 100 | 100 | - |
| **Matte** | Layer | Any layer in the composition | None | - |
| **Invert** | Checkbox | On or off | Off | - |

In the Effect Controls panel:

- **Light direction** is editable while **Texture** names a layer.
- **Relief** is editable while **Texture** names a layer.
- **Texture contrast** is editable while **Texture** names a layer.
- **Placement** is editable while **Texture** names a layer.
- **Scale** is editable while **Texture** names a layer.
- **Matte** scales how much of the effect each pixel gets: white applies it in full, black leaves the pixel as it arrived, grey part way. **Invert** reads the matte the other way round, light for dark.

## What each control does

- **Texture**: the layer to be pressed into this one.
- **Light direction**: direction from where the light falls across the relief.
- **Relief**: how far apart two points being compared are.
- **Texture contrast**: how strongly relief shows.
- **Placement**: what happens *outside* a copy of the texture. **Stretch** holds
  its edge outward, **Tile** repeats the texture, **Centre** leaves the rest of the frame
  untextured.
- **Scale**: large a copy of the texture is.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
