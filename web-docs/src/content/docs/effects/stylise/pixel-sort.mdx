## What it does

Every run of pixels whose value falls between **Min** and **Max** is put in order
along its own row or column. Pixels outside that band stay where they are. A run
never grows longer than **Maximum span length**, and **Random span offsets**
decides where each line's runs are cut.

## What each control does

- **Sort by**: which property a run is put in order by.
- **Direction**: **Horizontal** sorts along rows, **Vertical** down columns.
- **Span mode**: **Sort** writes the run back in order; **Stretch** gives the whole
  run the pixel the sort put at its far end; **Mirror** lays the run out from both
  ends inward.
- **Reverse**: orders every run the other way round.
- **Min**: the bottom of the band that sorts.
- **Max**: the top of it. Min above Max sorts nothing.
- **Maximum span length**: the most pixels one run may hold.
- **Random span offsets**: which offsets the runs take on each line.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** say where the runs may form, alongside **Min** and
  **Max**: a pixel sorts only where the matte is at least half lit. See
  [Effects](/use/effects/).

A value above 1 reads as 1, so a highlight brighter than white sits at the top of
the band.

:::note[Not built]
Runs run along rows or down columns. There is no angle between the two.
:::
