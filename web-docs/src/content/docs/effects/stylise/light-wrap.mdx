## What it does

This effect takes a layer, softens it, and paints the softened edge around the layer the effect is on.

## Parameters

{/* GENERATED:parameters - rewritten by `npm run docs:effects`. Edit the prose, not this block. */}

| Parameter | Control | Range | Default | Unit |
| --- | --- | --- | --- | --- |
| **Background** | Layer | Any layer in the composition | None | - |
| **Width** | Slider | 0 to 200; higher by typing | 0 | Pixels at composition size |
| **Intensity** | Slider | 0 to 3; higher by typing | 1 | - |
| **Mix** | Slider | 0 to 100 | 100 | - |
| **Matte** | Layer | Any layer in the composition | None | - |
| **Invert** | Checkbox | On or off | Off | - |

In the Effect Controls panel:

- **Matte** scales how much of the effect each pixel gets: white applies it in full, black leaves the pixel as it arrived, grey part way. **Invert** reads the matte the other way round, light for dark.

{/* END GENERATED */}

## What each control does

- **Background**: the layer whose light spills.
- **Width**: how far the wrap reaches inside the edge.
- **Intensity**: how strong the spill is.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
