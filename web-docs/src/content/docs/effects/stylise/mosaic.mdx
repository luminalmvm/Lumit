## What it does

The frame is cut into a grid of rectangles and every one is painted a single
colour. It is the pixelation effect.

| **Horizontal blocks** | Slider, whole numbers | 1 to 200; up to 2000 by typing | 24 | - |
| **Vertical blocks** | Slider, whole numbers | 1 to 200; up to 2000 by typing | 14 | - |
| **Sharp colours** | Checkbox | On or off | Off | - |
| **Mix** | Slider | 0 to 100 | 100 | - |
| **Matte** | Layer | Any layer in the composition | None | - |
| **Invert** | Checkbox | On or off | Off | - |

In the Effect Controls panel:

- **Matte** scales how much of the effect each pixel gets: white applies it in full, black leaves the pixel as it arrived, grey part way. **Invert** reads the matte the other way round, light for dark.

## What each control does

- **Horizontal blocks** and **Vertical blocks**: how many blocks span the frame
  across and down.
- **Sharp colours**: off, each block is the average of what is under it; on, each
  block is its centre pixel's colour.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
