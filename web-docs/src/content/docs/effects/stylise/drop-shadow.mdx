## What it does

creates a copy of the layer's shape and composites it behind the original layer.

## Parameters

| Parameter | Control | Range | Default | Unit |
| --- | --- | --- | --- | --- |
| **Shadow colour** | Colour | Each channel 0 to 4, scene-linear | 0, 0, 0, 1 | - |
| **Opacity** | Slider | 0 to 100 | 50 | - |
| **Direction** | Dial | Any angle; snaps every 15° while a modifier is held | 135° | - |
| **Distance** | Slider | 0 to 500; higher by typing | 12 | Pixels at composition size |
| **Softness** | Slider | 0 to 250; higher by typing | 8 | Pixels at composition size |

| **Mix** | Slider | 0 to 100 | 100 | - |
| **Matte** | Layer | Any layer in the composition | None | - |
| **Invert** | Checkbox | On or off | Off | - |

In the Effect Controls panel:

- **Matte** scales how much of the effect each pixel gets: white applies it in full, black leaves the pixel as it arrived, grey part way. **Invert** reads the matte the other way round, light for dark.

## What each control does

- **Shadow colour**: the colour of the drop shadow.
- **Opacity**: How intense the shadow is.
- **Direction**: direction the shadow applies in.
- **Distance**: how far from the original layer position the shadow moves.
- **Softness**: how blurred the shadow is. 
- **Shadow only**: keeps the shadow and throws the layer away.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
