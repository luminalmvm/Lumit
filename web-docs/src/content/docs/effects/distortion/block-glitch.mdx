## What it does

Cuts the picture into a grid and pushes the blocks around. 
Some are moved, and some split their colour channels; others repeat a short
slice of themselves.

## What each control does

- **Intensity** controls the amount every other control is scaled by.
- **Block size** sets size of blocks.
- **Rows/columns jitter** decides how far the grid lines separate.
- **Displacement** is how far a block is displaced, across the composition diagonal.
- **Channel offset** is how far a block's red and blue are split. 
- **Slice repeat** adjust how often a block repeats a strip of itself.
- **Seed** picks which random value the glitch is based on.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
