## What it does

Slide the input, and wraps around to the other side.

## Parameters

{/* GENERATED:parameters - rewritten by `npm run docs:effects`. Edit the prose, not this block. */}

| Parameter | Control | Range | Default | Unit |
| --- | --- | --- | --- | --- |
| **Shift x** | Slider | -3840 to 3840; any value by typing | 0 | Pixels at composition size |
| **Shift y** | Slider | -2160 to 2160; any value by typing | 0 | Pixels at composition size |
| **Mix** | Slider | 0 to 100 | 100 | - |
| **Matte** | Layer | Any layer in the composition | None | - |
| **Invert** | Checkbox | On or off | Off | - |

In the Effect Controls panel:

- **Matte** scales how much of the effect each pixel gets: white applies it in full, black leaves the pixel as it arrived, grey part way. **Invert** reads the matte the other way round, light for dark.

## What each control does

- **Shift x**, how far the picture moves to the right.
- **Shift y**, how far the picture moves down.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).

## Notes

**Offset and the Transform effect do different jobs.**
[Transform](/effects/utility/transform/) moves a layer and leaves emptiness
behind it. Offset moves the picture *within* its own frame and fills the gap with
the other side of itself. Use Transform to reposition a layer, and Offset to
reposition a texture.
