## What it does

Bezier warp gives each edge two handles, so an edge can bow, and the inside fills smoothly
between the bowed edges.

## What each control does

- **Upper left**, **Upper right**, **Lower right**, **Lower left** are the four
  corners, in pixels at composition size. Bezier warp starts with them on
  the layers's own corners.
- **Top edge**, **Right edge**, **Bottom edge**, **Left edge** each hold the two
  handles that bow that edge.
- **Quality** adjusts the math required to position each pixel.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the warp of the effect from another layer's brightness; see [Effects](/use/effects/).
