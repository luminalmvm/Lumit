Bezier warp is a **Distortion** effect.

## What it is for

[Corner pin](/effects/distortion/corner-pin/) lets you drag the four corners of
the picture and keeps the edges between them straight. Bezier warp gives each
edge two handles as well, so the edges can bow, and fills the inside smoothly
between them.

That is what you need to wrap a flat picture onto something curved: a label onto
a bottle, a graphic onto a curved screen, artwork onto a page as it turns, a
title onto a banner sagging between two poles.

The four corners carry the same names and the same units Corner pin uses, so
swapping one effect for the other costs no dragging.

## What each control does

- **Upper left**, **Upper right**, **Lower right**, **Lower left** — the four
  corners, in pixels at composition size. A fresh Bezier warp starts with them on
  the frame's own corners.
- **Top edge**, **Right edge**, **Bottom edge**, **Left edge** — each holds the two
  handles that bow that edge. They start closed, because most work begins with the
  corners. A handle sits a third of the way along its edge to begin with, which is
  the arrangement that makes a perfectly straight edge.
- **Quality** — how hard the effect works to place each pixel exactly. The default
  of 8 is well past the point where an ordinary warp stops moving; raise it if a
  very extreme bend looks approximate, lower it only if you are chasing speed.
- **Mix** — how much of the warped picture replaces the original.
- **Matte** and **Invert** — drive the effect from another layer's brightness;
  see [Effects](/use/effects/).

## Notes

**The default is exactly the identity.** With every point where it starts, the
picture comes back untouched — not softened by a resample, but pixel for pixel the
same. You can leave the effect on a layer while you decide what to do with it.

**Outside the bent shape is transparent.** The point of the effect is the shape,
so the frame around it is empty rather than smeared. Put whatever should be behind
it on a layer below.

**Quality is accuracy, not style.** It does not change the shape of the warp, only
how precisely each pixel finds its place, so it is not a control to animate.

**It cannot do perspective.** A Bezier warp bends edges; it does not make a plane
recede. If parallel lines in the picture need to converge, use
[Corner pin](/effects/distortion/corner-pin/) — and note that a Bezier warp with
its handles left at the thirds *is* a corner pin without the perspective.

**Pull a shape inside out and it stops.** A patch dragged so far that it folds
over itself has no single answer for the pixels in the fold; those come back
empty rather than as garbage.
