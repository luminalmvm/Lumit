## What it does

Warps the picture with a pattern of swirls.

The pattern is the same one [Fractal noise](/effects/generate/fractal-noise/)
draws.

## What each control does

- **Displacement**: **Turbulent** warps in both directions. **Horizontal** and 
  **Vertical** warp in a single direction.
- **Amount**: the amount a pixel can be displaced.
- **Size**: The scaling of the fracal noise driving the warp.
- **Complexity**: how many layers of finer fractal noise are added to the base.
- **Offset x** and **Offset y**: moves the underlying fractal noises position.
- **Evolution**: changes the phase of the fractal noise.
- **Cycle evolution** and **Cycle**: makes Evolution loop. With Cycle at 3, the
  Evolution at 0 and 3 full rotations are identical, so animating can loop with 
  no seam.
- **Pinning**: which edges are held still.
- **Seed**: which randomly generated fractal noise pattern to use.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
