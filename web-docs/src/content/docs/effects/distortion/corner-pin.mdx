## What it does

Drag the four corners of the layer to the four corners set in the effect, warping the layer
to retain straight edges between the points.

## What each control does

- **Upper left**, **Upper right**, **Lower left**, **Lower right** set the position
  of the four corners.
- **Edges** decides what fills the area a corner has been dragged away from.
  **Transparent** leaves it empty. **Repeat** smears the border pixel outward
  and **Mirror** reflects the picture back.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
