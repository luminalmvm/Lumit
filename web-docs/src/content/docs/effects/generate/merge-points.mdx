## What it does

Has four **Points** sockets, **Points**, **Points B**, **Points C** and **Points D**, and
sends every point wired into them out as one stream. A socket with nothing wired adds
nothing.

Added below two producers, it is wired to the nearest on Points and the next one up on
Points B. A producer whose points already reach it through the first is skipped.

The points are drawn as discs. No two share an identity, and a
[Trail](/effects/generate/trail/) below still follows each of them. The merged stream holds
at most 1,000,000 points, and past that the newest are kept.

Every point carries the socket it came in on under the name `source`, 0 for Points to 3
for Points D, whatever the two rows below say. An input that carries a `source` already
keeps its own apart, and each input's count on from the one before. See
[Names](/effects/generate/vary-points/#names).

## What each control does

- **Number by input**: sets the number each point carries to the socket it came in on, 0
  for Points to 3 for Points D. Off, each point keeps the number it came with.
- **Count nested inputs**: an input whose points already carry different numbers keeps them
  apart, and each input's numbers count on from the input before. A merge of an already
  merged pair and a third stream numbers them 0, 1 and 2.
- **Feather**: how soft the edge of a drawn disc is.
- **Mix**: how much of the drawing lands on the picture. At nought the points are still
  handed on.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness.
  See [Effects](/use/effects/).
