## What it does

Reads the stream on its **Points** socket and writes a label beside every point. The look
comes from a Text layer: its font, size, colour and style. The wording is a template, typed
into the **Text** row, or the Text layer's own text while that row is empty. The Text layer
can be hidden and still be read.

| In the template | Written as |
| --- | --- |
| `{index}` | The point's place in the stream. |
| `{number}` | The number it carries. |
| `{x}` and `{y}` | Where it is seen on the frame, in pixels at composition size. |
| `{id}` | Its id. |
| `{size}` | Its size. |
| `{age}` | Its age. |
| `{attr:NAME}` | The number it carries under the name NAME. |
| `{@NAME}` | One of the `@` names. `{@index}`, `{@id}` and `{@n}` are written whole. |

Any other text is written as it is, at every point. So is a token whose name reads nothing.
See [Names](/effects/generate/vary-points/#names).

Labels follow where the points are seen and do not turn with them. A point behind the
camera has no label.

## What each control does

- **Apply to**: which points get a label.
- **Group**: the group Picked and Not picked go by, as a name. Left empty, they go by the
  points a Pick points picked. See [Names](/effects/generate/vary-points/#names).
- **Threshold**: what a point's Group must read above to be in it. It is read only with a
  Group named.
- **Text layer**: the Text layer whose look the labels take. Unset draws nothing, unless
  this effect is on a Text layer.
- **Text**: the template. The Text layer then gives only the look. Left empty, the Text
  layer's own text is the template.
- **Decimals**: how many decimal places the numbers in a label are written to.
- **Offset x** and **Offset y**: how far across and down from its point a label sits.
- **Anchor**: which part of the label sits at that offset. **Left** runs the text away to
  the right of it, and **Right** to the left.
- **Max labels**: the most labels drawn. Past it the newest points keep theirs.
- **Mix**: how much of the result replaces the picture underneath.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness.
  See [Effects](/use/effects/).
