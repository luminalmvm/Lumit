## What it does

Randomly adjusts each pixel's brightness.

In the Effect Controls panel:

- **Matte** scales how much of the effect each pixel gets: white applies it in full, black leaves the pixel as it arrived, grey part way. **Invert** reads the matte the other way round, light for dark.

## What each control does

- **Amount**: how far a pixel can be pushed.
- **Distribution**: **Uniform** picks any value in the range with equal odds. 
  **Gaussian** clusters push values near zero, so most pixels move a little and few move a lot.
- **Colour noise**: off, grain is monochrome. On, each channel is randomised separately.
- **Animate**: on, a unique pattern each frame. Off, the pattern is frozen.
- **Seed**: randomises the grain pattern.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
