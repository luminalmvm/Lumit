## What it does

A point repeatedly emits a shape.

## What each control does

- **Producer x** and **Producer y**: the position to emit from.
- **Time**: adjusts the phase of the waves.
- **Frequency**: how many waves emit each second.
- **Expansion**: how fast a wave expands.
- **Lifespan**: how long a wave lives before disappearing.
- **Sides**: how many corners the shape has.
- **Star**: puts every second corner on an inner radius.
- **Star depth**: how deep star notches go, disabled unless star is checked.
- **Rotation**: rotates the shape around the centre point. 
- **Spin**: how far a wave turns each second as it travels.
- **Stroke width**: how thick each wave's outline is.
- **Colour**: the outline's colour.
- **Opacity**: how strong the outline is.
- **Fade in**: how much of a wave's life it spends fading in, as a percentage.
- **Fade out**: how much it spends fading out.
- **Composite on original**: on, the layer this effect is applied to is drawn underneath.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
