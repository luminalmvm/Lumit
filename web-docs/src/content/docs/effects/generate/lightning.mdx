## What it does

Draws a bolt of lightning which can be animated, and allows for customisation around forking and turbulence.

## What each control does

- **Origin x** and **Origin y**: start position.
- **Direction x** and **Direction y**: end position.
- **Type**: **Direction** lets the far end wander. **Strike** pins both ends. 
  **Omni** sends five bolts out in all directions from the origin.
  **Two-way strike** sends one from each point, meeting in the middle.
- **Conductivity state**: changes the bolts shape, similar to evolution in other effects.
- **Seed**: randomises the bolt generated.
- **Amplitude**: how far the bolt wanders off a straight line.
- **Forking**: how many branches leave the main bolt.
- **Decay**: how much dimmer the far end is than the root.
- **Core radius**: how thick the centre filament is.
- **Core colour**: the filament's colour.
- **Glow radius**: how far the halo reaches.
- **Glow colour**: the halo's colour. 
- **Glow opacity**: how strong the halo is.
- **Composite on original**: on, the layer Lightning is applied to appears under the bolt.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
