In the Effect Controls panel:

- **Scatter** groups **Density**, **Seed**.
- **Point** groups **Size**, **Feather**, **Colour**, **Max points**.
- **Matte** chooses which layer's alpha the points land inside, instead of this layer's own. **Invert** reads that matte inverted.
