## What it does

Wire a producer's **Points** socket into this effect and every point grows a tail.

## What each control does

- **Samples**: how many earlier moments are looked at.
- **Spacing**: how far apart in time those moments are.
- **Style**: **Dots** draws one dab per sample. **Segments** joins each dab to the one
  before it into a continuous ribbon.
- **Scale**: multiplies each point's own size.
- **Feather**: how soft a dab's edge is.
- **Fade**: how far the far end of a tail fades out.
- **Max trails**: the most points that may grow a tail.
- **Mix**: how much of the result replaces the picture underneath.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness;
  see [Effects](/use/effects/).
