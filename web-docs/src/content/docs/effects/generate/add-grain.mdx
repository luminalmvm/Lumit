## What it does

Add film grain onto a layer.

## What each control does

- **Intensity**: how strong the grain is.
- **Size**: how big a grain is.
- **Softness**: 0 gives hard-edged square cells.
- **Red**, **Green** and **Blue**: how much grain each channel gets, as a percentage of
  Intensity.
- **Monochrome**: if enabled the grain is monochrome.
- **Shadows**, **Midtones** and **Highlights**: how much grain each part of the tone range
  gets. 
- **Animate**: changes the grain pattern each frame automatically if enabled.
- **Seed**: which random grain pattern to use.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
