Water drop is a **Textures** effect.

## What it does

Draws a band of rings running out from **Centre**, starting at **Start time** and fading as
it spreads. The still surface is **Calm colour**. A crest is raised toward **Crest colour**
and a trough is lowered toward **Trough colour**.

It moves with the layer's time.

## Parameters

| Parameter | Control | Range | Default | Unit |
| --- | --- | --- | --- | --- |
| **Centre** | Point | Any position | 960, 540 | Pixels at composition size |
| **Wavelength** | Slider | 2 to 1000; any value by typing | 60 | Pixels at composition size |
| **Speed** | Slider | 0 to 5000; any value by typing | 400 | - |
| **Rings** | Slider, whole numbers | 1 to 40 | 6 | - |
| **Amplitude** | Slider | 0 to 100 | 100 | - |
| **Decay** | Slider | 0 to 100 | 40 | - |
| **Start time** | Slider | -60 to 60; any value by typing | 0 | Seconds |
| **Repeat** | Slider | 0 to 60; any value by typing | 0 | Seconds |
| **Calm colour** | Colour | Each channel 0 to 1 | 0.03, 0.12, 0.22 | - |
| **Crest colour** | Colour | Each channel 0 to 1 | 0.6, 0.8, 0.9 | - |
| **Trough colour** | Colour | Each channel 0 to 1 | 0, 0.02, 0.05 | - |
| **Paint** | Dropdown | Inside layer · Whole frame | Inside layer | - |

## What each control does

- **Centre**: where the drop falls.
- **Wavelength**: how far apart the crests are.
- **Speed**: how fast the rings spread, in pixels a second.
- **Rings**: how many crests deep the band is.
- **Amplitude**: how far the crests and troughs go toward their colours.
- **Decay**: how fast the rings fade as they spread.
- **Start time**: when the drop falls.
- **Repeat**: the time between one drop and the next. At 0 one drop falls.
- **Calm colour**, **Crest colour** and **Trough colour**: the colours of the still surface,
  the crests and the troughs.
- **Paint**: **Inside layer** paints only where the layer draws, and **Whole frame** fills
  the whole of the layer's picture.
- **Mix**: how much of the result replaces the original.
- **Blend**: the blend mode the result is laid over the original with.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
- **Channel**: the channel of the Matte layer that is read.
