## What it does

Making a repeatable pattern of fractal noise, with options for animation and complexity. 
Normally used as a base for more complex effects or textures.

## What each control does

- **Fractal type**: how each layer of detail is shaped and how the layers are combined; see
  [Fractal types](#fractal-types).
- **Noise type**: the pattern each layer is drawn from; see [Noise types](#noise-types).
- **Invert noise**: inverts the finished pattern.
- **Contrast**: increases the difference between white and dark areas of the noise.
- **Brightness**: lifts or darkens the noise after Contrast.
- **Rotation**: turns the noise pattern.
- **Uniform scaling**: when off, **Scale width** and **Scale height** scale separately.
- **Scale**: the size of one cell of the noise, with **Uniform scaling** on.
- **Offset x** and **Offset y**: offset the noise pattern's position.
- **Complexity**: how many layers of detail are contained in the fractal noise.
- **Sub influence**: amount to scale down how much each layer of complexity adds to the noise 
  relative to the last.
- **Sub scaling**: amount to scale down the size of each layer of complexity relative to the last.
- **Evolution**: the current phase of the fractal noise.
- **Cycle evolution** and **Cycle**: make Evolution loop. With Cycle at 3, the evolution at 0
  revolutions and the evolution at 3 full revolutions are the same, which allows for seamless looping.
- **Seed**: which random pattern is drawn.
- **Mix**: how much of the result replaces the original.
- **Blend**: the blend mode the result is laid over the original with.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
- **Channel**: the channel of the Matte layer that is read.

## Fractal types

| Fractal type | What it does |
| --- | --- |
| **Basic** | Adds the layers as they are. |
| **Turbulent** | Folds each layer about its middle. |
| **Turbulent smooth** | Folds each layer and rounds the crease into a soft dark valley. |
| **Turbulent sharp** | Folds each layer and narrows the crease into a thin dark line. |
| **Dynamic** | Folds each layer into bright puffs with dark veins between them, and moves each layer along the slope of the one before. |
| **Dynamic progressive** | As Dynamic, with the finer layers moving through **Evolution** faster. |
| **Dynamic twist** | Adds the layers as they are, each moved across the slope of the one before. |
| **Max** | Folds each layer and keeps the brightest in place of the sum. |
| **Smeary** | Shapes the layers as Dynamic does, and moves every finer layer along the slope of the first. |
| **Swirly** | Folds each layer as Turbulent does, each moved across the slope of the one before. |
| **Rocky** | Steepens each layer and clips it at black and white. |
| **Cloudy** | Lifts each layer towards white without folding it. |
| **Terrain** | Draws a ridge along the middle of each layer, with each finer layer strongest on the ridges of the one before. |
| **Subscale** | Adds the layers as they are, with the finer layers stronger where the pattern so far is bright. |
| **Strings** | Draws a thin bright line along the middle of each layer, with the finer layers fading twice as fast. |

## Noise types

| Noise type | What it does |
| --- | --- |
| **Value** | Gives each cell corner a random value and blends between them with a soft curve. |
| **Perlin** | Gives each cell corner a random slope and blends between them. The smooth, cloud-like pattern. |
| **Block** | Holds one value across each cell. |
| **Linear** | Blends the corner values in straight lines. |
| **Spline** | Runs a curve through the sixteen nearest values. |

## After Effects import

After Effects' Fractal Noise imports as Fractal noise. Each of its fifteen fractal types and
four noise types imports as the type of the same name. Its **Turbulent Basic** is
**Turbulent** here, and its **Soft Linear** is **Value**.
