Scratches is a **Textures** effect.

## What it does

Scatters thin curved strokes over a background, in layers. Each further layer's scratches
are shorter and closer together. A scratch thins and fades toward its ends.

## Parameters

| Parameter | Control | Range | Default | Unit |
| --- | --- | --- | --- | --- |
| **Layers** | Slider, whole numbers | 1 to 8 | 3 | - |
| **Length** | Slider | 4 to 2000; any value by typing | 200 | Pixels at composition size |
| **Width** | Slider | 0.2 to 20; any value by typing | 1 | Pixels at composition size |
| **Density** | Slider | 0 to 100 | 70 | - |
| **Steps** | Slider | 1 to 4; any value by typing | 1.6 | - |
| **Curl** | Slider | -100 to 100 | 20 | - |
| **Rotation** | Dial | Any angle | 30° | Degrees |
| **Spread** | Slider | 0 to 100 | 25 | - |
| **Scratch colour** | Colour | Each channel 0 to 1 | 0.7, 0.7, 0.7 | - |
| **Background colour** | Colour | Each channel 0 to 1 | 0.02, 0.02, 0.022 | - |
| **Seed** | Seed | Any whole number | A fresh random seed per instance | - |
| **Paint** | Dropdown | Inside layer · Whole frame | Inside layer | - |

## What each control does

- **Layers**: how many layers of scratches are drawn.
- **Length**: how long the first layer's scratches are.
- **Width**: how wide a scratch is at its middle.
- **Density**: how many of the places a scratch can fall hold one.
- **Steps**: how many times shorter each layer's scratches are than the layer before.
- **Curl**: how far each scratch bends.
- **Rotation**: the direction the scratches run.
- **Spread**: how far each scratch strays from Rotation. At 100 they run every way.
- **Scratch colour**: the colour of the scratches.
- **Background colour**: the colour behind them.
- **Seed**: where the scratches fall.
- **Paint**: **Inside layer** paints only where the layer draws, and **Whole frame** fills
  the whole of the layer's picture.
- **Mix**: how much of the result replaces the original.
- **Blend**: the blend mode the result is laid over the original with.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
- **Channel**: the channel of the Matte layer that is read.
