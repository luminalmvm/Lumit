## What it does

Paints a smooth run from one colour to another over the whole frame between two points.

## What each control does

- **Shape**: **Linear** runs the ramp along the line between two points. **Radial**
  runs it outward from Start, with End marking the outer edge.
- **Start x** and **Start y**: the starting point.
- **Start colour**: the colour at the start point.
- **End x** and **End y**: the end point .
- **End colour**: the colour at the end point.
- **Scatter**: displaces a pixel's position to add texture to the ramp.
- **Seed**: which random pattern the scatter follows.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
