title: Voronoi
description: "A cellular pattern of scattered points, drawn as cells, distances, edges or stones."

Voronoi is a **Textures** effect.

## What it does

Scatters one point in each cell of a grid and measures every pixel against the nearest
points. The result is coloured from the ramp. **Evolution** moves the points round, and
comes back to the start every 360°.

In the Effect Controls panel:

- **Edge width** is editable while **Mode** is set to Edges or Flagstone.
- **Line colour** is editable while **Mode** is set to Flagstone.
- **Exponent** is editable while **Distance metric** is set to Minkowski.
- **Smoothness** is editable while **Mode** is set to Smooth F1 or Flagstone.
- **Detail**, **Roughness** and **Lacunarity** are editable while **Mode** is set to
  Distance, F2 or Smooth F1.

## What each control does

- **Mode**: what is drawn.
  - **Cells** paints each cell one colour from the ramp.
  - **Distance** shades from each point at Position 0 outwards.
  - **Edges** draws the borders between cells at Position 100.
  - **F2** shades by the distance to the second nearest point.
  - **Smooth F1** is Distance with the creases between cells rounded off.
  - **Distance to edge** shades from the borders at Position 0 inwards.
  - **N-sphere radius** paints each cell by half the gap from its point to the nearest
    other point.
  - **Flagstone** draws each cell as a stone of one colour from the ramp, darker toward
    its edge, with a line of Line colour between the stones.
  - **Chess cells** cuts each cell in four through its point, and paints the quarters
    Position 0 and Position 100 by turns.
  - **Plasma** shades by the nearest distance over the second nearest.
- **Cell size**: how big the cells are.
- **Randomness**: how far the points stray from a grid. At 0 they line up.
- **Evolution**: moves every point round a small circle.
- **Offset**: slides the whole pattern.
- **Edge width**: how thick the borders are on Edges, and the line on Flagstone.
- **Line colour**: the colour of the line between the stones of Flagstone.
- **Distance metric**: how distance is measured. **Euclidean** is the straight line,
  **Manhattan** adds the distance across to the distance down, **Chebychev** takes the
  greater of the two, and **Minkowski** bends between them by Exponent. Distance to edge and
  the line of Flagstone are always measured Euclidean.
- **Exponent**: the shape of Minkowski. 1 is Manhattan, 2 is Euclidean, and high values
  near Chebychev.
- **Smoothness**: how far the creases of Smooth F1 are rounded, and how far the edge of
  Flagstone's line fades.
- **Detail**: how many finer layers of the pattern are laid over the first.
- **Roughness**: how strong each finer layer is beside the one before it.
- **Lacunarity**: how many times finer each layer is than the one before it.
- **Seed**: where the points fall.
- **Paint**: **Inside layer** paints only where the layer draws, and **Whole frame** fills
  the whole of the layer's picture.
- **Interpolation**: how one stop meets the next. **Smooth** eases between them, and
  **Constant** holds each colour until the next stop.
- **Progression**: how the ramp is read from end to end. **Quadratic** stretches the start
  of the ramp, and **Easing** stretches both ends.
- **Stops**: how many colours are used, from Colour 1.
- **Colour 1** to **Colour 5** and **Position 1** to **Position 5**: each stop's colour,
  and where it sits on the ramp. Stops are sorted by Position.
- **Mix**: how much of the result replaces the original.
