## What it does

Applies the alpha or any other channel from a layer as the alpha on the source layer.

| **Combine with existing alpha** | Checkbox | On or off | Off | - |
| **Mix** | Slider | 0 to 100 | 100 | - |
| **Matte** | Layer | Any layer in the composition | None | - |
| **Invert** | Checkbox | On or off | Off | - |

In the Effect Controls panel:

- **Matte** is the alpha: the chosen channel of the matte layer becomes this layer's coverage, which is the whole effect rather than a strength applied to one. **Invert** inverts the mattes for calculating strength.

{/* END GENERATED */}

## What each control does

- **Matte**: the layer whose channel becomes transparency.
- **Invert**: read the matte the other way round.
- **Channel**: which colour or alpha channel to use as the source for the new alpha.
- **Combine with existing alpha**: intersects the new and existing alphas.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
