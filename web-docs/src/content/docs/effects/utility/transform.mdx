## What it does

The layer transform group (anchor, position, scale, rotation and opacity) as an
effect.

| **Anchor x** | Slider | -1000 to 1000; any value by typing | 0 | Pixels at composition size |

In the Effect Controls panel:

- **Matte** scales how much of the effect each pixel gets: white applies it in full, black leaves the pixel as it arrived, grey part way. **Invert** reads the matte the other way round, light for dark.

## What each control does

- **Anchor x** and **Anchor y**: the point everything else happens around.
- **Position x** and **Position y**: slides the frame left/right and up/down.
- **Scale x %** and **Scale y %**: scale size as a percentage.
- **Rotation**: turn a set number of degrees.
- **Opacity %**: how much of the transformed picture there is.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
