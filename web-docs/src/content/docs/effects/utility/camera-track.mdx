## What it does

Tracks the footage and allows you to recreate the camera path within Lumit. Apply it 
to a layer and press **Analyse**. You can keep editing while it runs. 
The whole source clip is analysed, so every clip using that footage shares the one
solve. Trimming, moving or retiming a clip doesn't track it again.

## What each control does

- **Analyse**: start tracking.
- **Cancel**: stop a track that's running.
- **Feature density**: how many points are tracked. More is slower but copes better
  with hard footage.
- **Use masks**: masks on the layer are left out of the track. Use this for anything
  moving on its own, like a person.
- **Show points**: draws the solved points over the picture. Select some to create a
  null or solid at their position.
