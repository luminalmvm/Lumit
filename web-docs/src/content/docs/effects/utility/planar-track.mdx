## What it does

Used to track a rectangle on an object

Where the surface stops being followable, the analysis stops there and keeps the part that
worked.

## What each control does

- **Analyse**: start tracking.
- **Cancel**: stop a track that is running.
- **Create corner pin**: put a keyframed Corner pin on the layer named below.
- **Upper left**, **Upper right**, **Lower left** and **Lower right**: the four corners of
  the surface.
- **Pin layer**: which layer the Corner pin is put on.
- **Feature density**: how many specks the tracker chases inside the quad. More is slower
  but copes better with a plain or badly lit surface.
- **Use masks**: masks on the layer are left out of the track.
