## What it does

Node graph applies a [node graph composition](/use/node-graphs/) to the layer. The
layer's picture at this point in the stack goes in as the graph's first picture Input, the
graph's other Input boxes appear as rows on this effect, and the graph's Output is what
comes out. It is added from the **Node graphs** kicker of the effects console rather than
by name, and one node graph applied inside another is how graphs nest. A composition is
refused on itself.

## What each control does

- **Open graph**: fronts the node graph composition this effect applies.
- The rows above Mix are the graph's Inputs, one per Input box, with the box's kind, range
  and default.
- **Mix**: how much of the graph's Output is used over the picture that went in.
- **Blend**, **Matte**, **Invert**, **Channel**: the blend and matte rows every effect has.
