## What it does

Maps a number from one range onto another linearly.

## What each control does

- **Value**: the number coming in. Usually wired from another driver rather than typed.
- **In low** and **In high**: the range the number arrives in. Set these to what the thing
  feeding you actually produces — an [Audio level](/effects/drivers/audio-level/) rarely
  reaches 1, so an In high of about 0.4 uses the whole of the response.
- **Out low** and **Out high**: the range it should leave in, in the driven parameter's
  units.
- **Clamp**: holds the result inside the output range. On by default.
