## What it does

Fires an event on each beat marker, on each beat found in the sound, or each time one band
of the sound gets louder than **Threshold**. It has four sockets: **Pulse**, 1 on the frame
of an event and 0 otherwise, **Count**, the events so far, **Envelope**, 1 at each event and
falling away over **Decay**, and **Time since last**, in seconds.

Every value is worked out from the start of the composition, so scrubbing and exporting give
the same numbers.

## What each control does

- **Events**: **Beat markers** fires on the composition's beat markers. **Detected beats**
  finds beats in the sound, as **Composition ▸ Detect beats** does. **Level crossing** fires when the
  band's level rises past **Threshold**.
- **Source**: the sound listened to, the composition's mix, one layer of it or one clip.
- **Audio**: the layer **Layer** and **Clip** listen to.
- **Clip**: the clip **Clip** listens to.
- **Band**: the whole sound, below 200 Hz, or above 4 kHz.
- **Sensitivity**: how readily a beat is found.
- **Minimum gap**: of two beats closer than this, the stronger counts.
- **Threshold**: the level the band has to rise past.
- **Hold off**: frames after a crossing before the next can fire.
- **Decay**: how fast **Envelope** falls. It is down to about a third after this long.
