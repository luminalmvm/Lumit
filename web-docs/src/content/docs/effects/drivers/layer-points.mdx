## What it does

Hands out another layer's points. A wire never crosses between layers, so this node names
the layer instead, the way [Audio level](/effects/drivers/audio-level/) does. Its
**Points** socket is the same socket a producer has, so anything that takes a points wire
takes this one.

The points are the ones that layer draws, with that layer's own wires applied. If the
named layer carries more than one producer, the first is tapped; there is no picker for
the second yet.

A tap reaches one layer and no further: a layer that is itself tapping a third layer reads
as empty. So does no layer named, a deleted layer, a layer with no producer, a producer
that is switched off, and a [Scatter](/effects/generate/scatter/) or
[Emit from image](/effects/generate/emit-from-image/), whose points depend on a picture
that does not exist at the moment this is read.
