## What it does

Puts out a colour whose hue turns through the wheel at a rate you set.

## Parameters

{/* GENERATED:parameters - rewritten by `npm run docs:effects`. Edit the prose, not this block. */}

| Parameter | Control | Range | Default | Unit |
| --- | --- | --- | --- | --- |
| **Phase** | Slider | 0 to 1; any value by typing | 0 | - |
| **Rate** | Slider | -2 to 2; any value by typing | 0.2 | - |
| **Saturation** | Slider | 0 to 100 | 100 | Per cent |
| **Brightness** | Slider | 0 to 100; higher | 100 | Per cent |

{/* END GENERATED */}

## What each control does

- **Phase**: where on the wheel it starts. Turns rather than degrees, so a
  [Wiggle](/effects/drivers/wiggle/) with a value of 1 wired in here sweeps exactly one
  revolution.
- **Rate**: turns per second.
- **Saturation**: how coloured it is.
- **Brightness**: per cent of white. It can be increased past 100.
