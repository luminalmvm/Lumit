## What it does

Applies one of the looks the project's OCIO config defines, between two of its colour
spaces. The look runs in its own process space. **Inverse** runs it backwards.

:::note[Needs a config]
With no config loaded, or a look or space the config does not have, the effect passes
the layer through unchanged.
:::

## What each control does

- **Input colour space**: the space the layer's pixels are taken to be in.
- **Look**: the look, from the config.
- **Output colour space**: the space the result is written in.
- **Inverse**: run the look backwards.
- **Mix**: how much of the result replaces the original.
- **OCIO configuration**: the name of the project's config, read-only.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
