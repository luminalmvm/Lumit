## What it does

Similar to [Tint](/effects/colour/tint/), but with three colours, one for blacks, mid-tones, and whites.

## Parameters

| Parameter | Control | Range | Default | Unit |
| --- | --- | --- | --- | --- |
| **Highlights** | Colour | Each channel 0 to 4, scene-linear | 1, 0.98, 0.9, 1 | - |
| **Midtones** | Colour | Each channel 0 to 4, scene-linear | 0.45, 0.3, 0.22, 1 | - |
| **Shadows** | Colour | Each channel 0 to 4, scene-linear | 0.02, 0.03, 0.1, 1 | - |
| **Mix** | Slider | 0 to 100 | 100 | - |
| **Matte** | Layer | Any layer in the composition | None | - |
| **Invert** | Checkbox | On or off | Off | - |

In the Effect Controls panel:

- **Matte** scales how much of the effect each pixel gets: white applies it in full, black leaves the pixel as it arrived, grey part way. **Invert** reads the matte the other way round, light for dark.

{/* END GENERATED */}

## What each control does

- **Highlights** — the colour white maps to.
- **Midtones** — the colour mid-grey maps to.
- **Shadows** — the colour black maps to.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).

## Notes

**For an even simpler two-colour version**, use [Tint](/effects/colour/tint/).
For a two-tone stencil with no ramp at all, use
[Threshold](/effects/colour/threshold/).
