## What it does

Adjust the brightness against brightness values. You can view this as inputting 
brightness into a function which outputs a different brightness based on the curve
you set.

## What each control does

- The interface can be used to directly alter the curve.
- **Black**, **Shadows**, **Midtones**, **Highlights** and **White** are the
  channel's curve outputs at inputs 0, 0.25, 0.5, 0.75 and 1.
- **Master** applies to all three channels, while **Red**, **Green** and
  **Blue** apply to individual channels.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
