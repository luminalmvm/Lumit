## What it does

Converts the layer's pixels from one colour space of the project's OCIO config to
another. The lists come from the config chosen in **File ▸ Project settings ▸ Colour**.
A space left at **Working space** is the space Lumit composites in, so setting only
**Output colour space** is an output transform and setting only **Input colour space** is
an input transform.

:::note[Needs a config]
With no config loaded, or a name the config no longer has, the effect passes the layer
through unchanged.
:::

## What each control does

- **Input colour space**: the space the layer's pixels are taken to be in.
- **Output colour space**: the space the pixels are converted to.
- **Mix**: how much of the result replaces the original.
- **OCIO configuration**: the name of the project's config, read-only.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
