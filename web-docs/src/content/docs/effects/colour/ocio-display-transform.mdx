## What it does

Runs the layer through a display and view of the project's OCIO config, the same
transform the Viewer's colour picker offers, baked into the layer. **Inverse** runs the
view backwards, which takes a display-referred picture back to scene-linear.

:::note[Needs a config]
With no config loaded, a display or view the config does not have, or an inverse the
view's tables cannot give, the effect passes the layer through unchanged.
:::

## What each control does

- **Input colour space**: the space the layer's pixels are taken to be in.
- **Display**: the display, from the config.
- **View**: one of the chosen display's views.
- **Inverse**: run the view backwards.
- **Mix**: how much of the result replaces the original.
- **OCIO configuration**: the name of the project's config, read-only.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
