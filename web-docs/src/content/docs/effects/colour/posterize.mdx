## What it does

Posterize recreates the effect of displaying an input in a reduced colourspace.

Each of the red, green and blue channels is stepped separately.

## Parameters

{/* GENERATED:parameters - rewritten by `npm run docs:effects`. Edit the prose, not this block. */}

| Parameter | Control | Range | Default | Unit |
| --- | --- | --- | --- | --- |
| **Levels** | Slider, whole numbers | 2 to 64; up to 255 by typing | 8 | - |
| **Mix** | Slider | 0 to 100 | 100 | - |
| **Matte** | Layer | Any layer in the composition | None | - |
| **Invert** | Checkbox | On or off | Off | - |

In the Effect Controls panel:

- **Matte** scales how much of the effect each pixel gets: white applies it in full, black leaves the pixel as it arrived, grey part way. **Invert** reads the matte the other way round, light for dark.

{/* END GENERATED */}

## What each control does

- **Levels** — how many shades each channel keeps.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).

## Notes

**Bright highlights are kept.** A specular above white is banded on the same
ladder rather than clipped to white.

**Posterize works on colour, not transparency.** Posterize does not apply to the alpha channel.

**For two-tone black-and-white**, use [Threshold](/effects/colour/threshold/). 
Posterize at Levels 2 keeps colour, and Threshold does not.
