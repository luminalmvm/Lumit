## What it does

Photo filter adjusts the temperature of a shot the same way coloured glass in 
front of a camera lens would.

## What each control does

- **Filter** — which preset filter colour to use.
- **Colour** — used when Filter is set to Custom to pick custom colours.
- **Density** — how intense the effect is.
- **Preserve luminosity** — preserves the brightness of pixels when altering colour.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).

## Notes

**For a warmth control with a temperature scale**, use
[Temperature](/effects/colour/temperature/), which works in kelvin. Photo filter
works by choosing a glass.
