## What it does

Adjust how colourful the output is. At zero it's greyscale.


Every pixel's colourfulness is multiplied by the same amount, regardless of it's
input saturation.

## What each control does

- **Saturation** — the multiplier on colourfulness, as a percentage. Zero is
  greyscale and the neutral point passes through untouched. There is no real
  ceiling: the slider reaches a heavy lift and typing goes further, because the
  mix between grey and colour keeps extrapolating past it, which is a legitimate
  if aggressive look.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).

## Notes

For when a picture already has saturated areas, [Vibrancy](/effects/colour/vibrancy/) is the better tool.
It preserves already saturated areas while boosting less colourful areas.
