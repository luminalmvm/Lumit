## What it does

Applies a **look-up table**. This must be a `.cube` file, and is loaded from
disk.

:::caution[Two limits worth knowing]
The table is applied to the scene-linear working picture as it stands, with no
conversion into the space the LUT was authored for. A LUT built for
display-encoded or log input will therefore not land the way its author
intended. The tables that behave predictably are those authored against linear
input.
:::

## What each control does

- **File** — the .cube file to apply.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
