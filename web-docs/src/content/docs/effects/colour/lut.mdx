## What it does

Applies a **look-up table**. This must be a `.cube` file, and is loaded from
disk.

:::note[Set Input space to whatever the LUT expects]
**Input space** says which space the table was written for: the picture is
converted into that space, the table applies, and the result comes back to
linear. Log-encoded LUTs have no matching option yet.
:::

## What each control does

- **File**: the .cube file to apply.
- **Input space**: the encoding the table was authored for.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
