## What it does

Applies a look-up table or an ASC CDL grade from a file, read the way an OCIO config
reads its own files. No config is needed. A cube is sampled tetrahedrally, where the
[LUT](/effects/colour/lut/) effect samples trilinearly. A `.ccc` or `.cdl` file with
several grades applies the first.

:::note[Unset or unreadable]
An unset, missing or unreadable file passes the layer through unchanged. **Inverse** on
a 3D table passes the layer through as well.
:::

## What each control does

- **File**: the LUT or CDL file to apply.
- **Inverse**: run the file's transform backwards.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
