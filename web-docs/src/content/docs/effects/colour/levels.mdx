## What it does

Levels lets you adjust the black/white point and gamma through a ui, or adjust values directly.
You can adjust these values per channel, including alpha.

In the Effect Controls panel:

- **Master** groups **Input black**, **Input white**, **Gamma**, **Output black**, **Output white**.
- **Red** groups **Input black**, **Input white**, **Gamma**, **Output black**, **Output white**, and starts closed.
- **Green** groups **Input black**, **Input white**, **Gamma**, **Output black**, **Output white**, and starts closed.
- **Blue** groups **Input black**, **Input white**, **Gamma**, **Output black**, **Output white**, and starts closed.
- **Matte** scales how much of the effect each pixel gets: white applies it in full, black leaves the pixel as it arrived, grey part way. **Invert** reads the matte the other way round, light for dark.

## What each control does

- **Input black** — the input value that comes out as Output black. Raise it to
  crush blacks.
- **Input white** — the input value that comes out as Output white. Lower it to
  blow out highlights.
- **Gamma** — same as [Gamma](/effects/colour/gamma/).
- **Output black** and **Output white**. Raising Output black raises the black level, 
  Lowering Output white reduces the back brightness.
- **Master** applies to all three channels, while **Red**, **Green** and **Blue**
  apply to individual channels.
- **Mix**: how much of the result replaces the original.
- **Matte** and **Invert** drive the strength of the effect from another layer's brightness; see [Effects](/use/effects/).
